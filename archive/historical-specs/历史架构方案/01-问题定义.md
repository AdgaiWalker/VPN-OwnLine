## 一句话

> **把任意一台「有 root 的 Linux 服务器」，变成客户端里一条能用的节点；**
> **别人给我一条链接，也能变成同样的一条。**

## 给谁用

**第一阶段：只给我自己。** 用顺手了再一个一个加能力，最后才给别人用——而且不是"我给",是**"互相给"**。

| 阶段 | 目标 | 判断标准 |
|---|---|---|
| 自己用 | 加一台机器 ≤2 步，装完能用 | 我能独立完成，不需要问人 |
| 一个个加 | 每次只加一个能力 | 加完不影响已有功能 |
| 互相用 | 朋友给的一条链接，我能直接用 | 粘贴 → 订阅里出现 → 能连 |
| 给别人用 | 别人照着做也能成 | 他没问过我 |

## 两个入口（核心设计）

```
① 我有服务器   IP + 密码/私钥  →  装成节点   （重，已有基础）
② 我有链接     vless://...     →  粘进订阅   （轻，几行代码）
```

**为什么必须有第二个入口**：

- "给别人用"要求对方会装机器 → 支持成本极高
- "互相用"只要求对方给一条链接 → **成本几乎为零**
- 交换的东西天然可持续，赠予的不可持续

**顺序**：先把 ① 跑通，再加 ②。因为 ① 是地基，② 是复用。

## 现在的状态（2026-10-26）

- ✅ 4 台腾讯云机器已变成节点，能扫码导入 Shadowrocket
- ✅ 面板能加/删/改名/换密钥，能看流量和探活
- ❌ 只能加腾讯云列表里的机器，其他云要手动填，且只支持密码、不支持密钥
- ❌ 装的时候不问「这台是出口还是中转」，装完才发现国内机翻不了墙
- ❌ 装完只探活，不验证「从这台出去是什么 IP」
- ❌ 不能接收别人给的节点链接

## 第一版做什么（四件，按顺序）

1. **通用接入**：任意 IP/域名 + root 密码 **或 SSH 私钥**（腾讯云列表降为快捷方式）
2. **角色选择**：装的时候选「出口」或「中转」，配置不同
3. **装完自测**：端口通不通、握手对不对、出口 IP 是不是这台
4. **粘链接**：粘贴 vless:// 链接 → 校验 → 进订阅

## 明确不做

| 不做 | 为什么 |
|---|---|
| cloud-init / Serverless / Cloudflare Workers | 不是"有 root 的 Linux"，是另一类东西 |
| 多级链式、负载均衡 | 一台都没跑稳，谈不上编排 |
| 自愈、自动切换 | 成本比前两层加起来还高 |
| 电商环境（住宅 IP、浏览器隔离）| 预算差 15 倍，且不是"节点"问题 |
| 自研客户端 | 交付物是订阅，客户端用现成的 |
| 公开注册 / 计费 / 风控 | 那是机场，另一个行业 |

## 成功的标准

**一周后能回答这四个问题：**

1. 加一台新机器（任意云、任意 IP），我能在 **5 分钟内**独立装好
2. 装完之后，我**知道这台是出口还是中转**，也知道它能不能翻墙
3. 出问题我能说出**哪一步坏的**（连不上 / 装不上 / 端口没开 / 角色装错）
4. 朋友给我一条链接，我**30 秒内**能用上

## 发布策略（版本与仓库）

> 原则：**小步发布，边界清晰时才拆仓。**

### 版本节奏

| 版本 | 内容 | 发布给谁 |
|---|---|---|
| v0.x | 自用（腾讯云 + 密码）| 只有我 |
| v1.0 | 通用接入（任意 IP + 密码/私钥）| 只有我，稳定后用 |
| v1.1 | 角色选择（出口 / 中转）| 只有我 |
| v1.2 | 装完自测（出口 IP 可见）| 只有我 |
| v2.0 | 粘链接（互相用的入口）| 小圈子（3~5 人）|
| v3.0 | 公开 | 不做 |

### 什么时候建独立仓库

**满足两条才拆：**

1. 这个模块**会独立演化**（不跟随主项目版本）
2. 有**第二个人想单独用它**（不是用整套）

候选拆分点（现在不拆，先记下）：

| 模块 | 独立价值 | 拆的时机 |
|---|---|---|
| 安装器（addnode） | 别人只想装节点，不要面板 | 有第 2 个人问"能不能单独给我" |
| 面板（web） | 别人已有节点，只想要界面 | 同上 |
| IP 体检（ipcheck） | 通用小工具 | 它自己有 3 个以上用途 |

**不拆的理由**：拆早了要维护两套版本号、两套 CI、两套文档——比省下的耦合成本高。

## 递增规则（给自己定的规矩）

> **每次只加一个能力，加完必须能用一句话验收；不能用一句话验收的，就是加多了。**

| 顺序 | 加什么 | 一句话验收 |
|---|---|---|
| 1 | 任意 IP + 密码 | 阿里云一台能装上 |
| 2 | 支持私钥 | 只给密钥的机器能装上 |
| 3 | 角色：中转 | 广州机能当跳板用 |
| 4 | 装完自测出口 IP | 面板上能看到"这台从哪出去" |
| 5 | 粘链接 | 朋友给一条 vless 链接，30 秒能用 |

**前一条没验收通过，不加下一条。**

## 一个规矩（有第二个人用之后生效）

> **有第二个人在用，就不能随便改。**
> 改字段 = 他的客户端导入失败；换端口 = 他的订阅失效。
> 所以：一旦有第二个人用，**先加版本号，再改。**

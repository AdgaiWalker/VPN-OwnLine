## 1. 背景

用户为非程序员，持有 4 台腾讯云轻量服务器（1 台海外 ¥99/年，3 台国内），
日常需求依次为：**用海外 AI（Claude / GPT / Codex）→ 可能做电商 → 把方法讲给别人**。

现有系统（自建，已运行）能做节点增删改、订阅分发、探活、流量展示。但它假设"只有腾讯云"，暴露四个缺口：

1. 只能从腾讯云列表选机器；手填只支持密码，不支持私钥
2. 装的时候不问用途，国内机装完才发现翻不了墙
3. 装完只探活，不验证"这台从哪出去"
4. 无法接收别人给的节点（"互相用"无处落地）

---

## 2. 目标与非目标

### 2.1 目标

> **把任意一台「有 root 的 Linux 服务器」变成客户端里一条能用的节点；别人给的一条链接，也能变成同样的一条。**

### 2.2 非目标

| 非目标 | 理由 |
|---|---|
| 公开注册、计费、配额 | 那是机场，另一个行业 |
| 电商环境（住宅 IP、浏览器隔离）| 预算差 15 倍，且不是"节点"问题 |
| 自研客户端 | 交付物是订阅，客户端用现成的 |
| 多级链式 / 负载均衡 / 自愈 | 一台都没跑稳，谈不上编排 |
| Cloudflare Workers / Serverless | 不是"有 root 的 Linux" |

### 2.3 成功判定（一周后）

1. 加一台任意云的新机器，5 分钟内独立装好
2. 装完知道它是出口还是中转、能不能翻墙
3. 出问题能定位到具体环节
4. 朋友给一条链接，30 秒内能用上

### 2.4 已决定的产品决策（v1.1 拍板）

| # | 决策 | 理由 | 可回退吗 |
|---|---|---|---|
| D1 | **中转节点不进订阅** | 本期做不了跳板，进订阅只会让人误选后"连了没网" | 能，T3 实现后再进 |
| D2 | **外部节点标来源，且不可换密钥** | 我们对它没有控制权；不标来源，出事分不清责任 | 不建议回退 |
| D3 | **主控重启后不恢复任务，只提示"已中断"** | 恢复安装要落盘 + 状态机（半天）；不骗人只要 1 小时。先保证不骗人 | 能，二期做恢复 |

## 3. 用户与场景

**唯一用户：本人（非程序员）。** 后续阶段才扩展。

| 场景 | 触发 | 现在 | 期望 |
|---|---|---|---|
| S1 买新机器 | 云厂商买完 | 手填 IP + 密码，常失败 | 填 IP + 密码或私钥，一路走完 |
| S2 国内机当跳板 | 已有国内机 | 装完才发现翻不了墙 | 装时选"中转" |
| S3 朋友给节点 | 收到 vless 链接 | 无法使用 | 粘贴 → 进订阅 |
| S4 判断连哪条 | 每天打开 | 靠猜 | 面板给一句带依据的建议 |
| S5 出问题 | 连不上 | 截图问人 | 面板说清哪一步坏了 |
| S6 节点被墙 | 突然全红 | 不知道是被墙还是坏了 | 提示"可能被墙"，给换 IP 指引 |

## 5. 功能需求

### FR-1 通用接入（P0）

- **描述**：任意 IPv4 / 域名 + 认证方式二选一（root 密码 / SSH 私钥）
- **输入**：地址、SSH 端口（默认 22）、用户名（默认 root）、密码 **或** 私钥
- **输出**：安装任务（job），四步进度，最终产出节点参数
- **验收**：
  - 腾讯云、阿里云各一台能装上
  - **只给私钥（无密码）** 的机器能装上
  - 非法地址 → 400「地址格式不对（IP 或域名）」
  - 空认证 → 400「密码或私钥至少填一个」

### FR-2 角色选择（P0）

- **描述**：安装前必须选「出口 exit」或「中转 relay」，不可跳过
- **落地的数据形态**（v1.1 新增定义）：中转必须指定落地，落地 = 一条完整 vless 参数
  `{host, port, uuid, pbk, sid, sni}`
- **落地的输入方式**（二选一）：
  1. 从已有节点里选一条
  2. 粘贴一条 vless 链接
- **输出**：不同的 sing-box 配置（中转需 outbound 指向落地）
- **验收**：
  - 未选角色时「开始安装」置灰
  - 选「中转」但未指定落地 → 阻断并提示「请先选择或粘贴落地节点」
  - 装完节点列表显示角色标签
  - **中转节点不出现在订阅中**（D1）

### FR-3 装完自测（P0）—— v1.1 按角色拆开

- **描述**：安装成功后自动验证，结果写入节点记录
- **出口（exit）节点测三项**：端口连通 / TLS 握手 / **出口 IP 与节点所在地一致**
- **中转（relay）节点测两项**：端口连通 / TLS 握手；**不测出口 IP**（国内机访问境外 IP 查询会被拒，必然误报）
- **中转额外测一项**：能否连到落地（TCP 可达即可）
- **输出枚举**：`ok / port / tls / role_mismatch / timeout`
- **验收**：
  - 关掉 sing-box → `tls`
  - 关掉云防火墙端口 → `port`
  - 国内机选"出口"→ `role_mismatch` 并给出说明
  - 国内机选"中转"→ 不出现 `role_mismatch`

### FR-4 粘链接（P0）

- **描述**：粘贴 `vless://` 链接，校验后加入订阅
- **输入**：字符串（可多条，按换行分隔）
- **必填字段校验**：`uuid / host / port / pbk / sid / sni`
- **输出**：节点记录，`source=external`，`health=unknown`
- **验收**：
  - 合法链接 30 秒内出现在订阅
  - 缺字段 → 拒绝并说明缺哪个（如「缺少 pbk（Reality 公钥）」）
  - **外部节点不显示绿点**，显示「未验证（外部节点）」——因为探活对 Reality 是假阳性
  - 外部节点无「更换密钥」入口

### FR-5 节点列表与订阅（P0，已有，需保持）

- 订阅按 UA 分发 clash / v2ray；节点变更后自动刷新
- **验收**：节点变化后 10 秒内订阅同步；两种格式节点数一致

### FR-6 决策提示（P1）

- **描述**：每条节点给一句人话建议，**必须显示依据**
- **依据**：延迟、角色、当日流量、health
- **示例**：「硅谷 · 107ms · 今日 0.04GB → AI 首选」「新加坡 · 600ms → 日常可用，AI 偏慢」
- **验收**：每条有建议 + 依据；依据数据变化时建议跟着变；建议错了能看出是哪项数据错

### FR-7 来源标记（P1）

- 节点区分 `builtin`（自建）/ `external`（外部链接）/ `relay`（中转）
- **验收**：列表与订阅都能看出；外部节点不可换密钥

### FR-8 订阅轮换（P0，v1.1 新增）

- **描述**：一键作废旧订阅 token，生成新 token
- **验收**：
  - 旧链接立即 404
  - 二维码自动重绘
  - **明确提示：轮换 token 不会踢掉已连接设备**（要踢人得换 UUID）

## 6. 非功能需求

| 编号 | 类别 | 要求 | 验收 |
|---|---|---|---|
| NFR-1a | 性能 | 海外/镜像可用：单台 ≤2 分钟 | 实测计时 |
| NFR-1b | 性能 | 国内/镜像不稳：单台 ≤8 分钟 | 实测计时 |
| NFR-1c | 口径 | 以上均**不含**"人工去控制台开端口"的等待 | 记录说明 |
| NFR-2 | 幂等 | 重装同一台：①节点条数不变 ②**旧 UUID 被替换**（不是新增）③旧设备确实断开 | 连续装两次逐条核对 |
| NFR-3 | 兼容 | Ubuntu 20+/Debian 11+/Rocky 9；x86_64/arm64。**CentOS 7 已 EOL，glibc 2.17 可能不支持，标"待实测"，不作为承诺** | 三种系统各装一台 |
| NFR-4 | 安全 | 节点私钥不出服务器；云密钥文件 600；面板 Basic Auth；未认证接口 401 | 安全自检 |
| NFR-5 | 可观测 | 每步有日志；失败有错误码 + 中文文案 | 制造 3 种失败，文案可读 |
| NFR-6 | 成本 | **系统本身**不新增支出（不含用户自购机器）| 账单对比 |
| NFR-7 | 恢复 | 主控重建后 30 分钟内恢复（按文档）| 演练一次 |
| NFR-8 | 不打扰 | 探活失败不删除节点、不自动改配置 | 断网 10 分钟后节点仍在 |
| NFR-9 | 超时 | 单次安装 **15 分钟**超时，超时标 `timeout` 并中止 | 模拟慢源触发 |
| NFR-10 | 容量 | 单主控 **≤20 节点**（探活 60 秒一轮的成本上限）| 压测或推算说明 |

**硬约束**：**任何失败都不得让已有节点从订阅中消失。**

## 7. 兜底设计（核心章节）

> 原则：每一步失败都要有「用户看到什么 / 系统做什么 / 你手动做什么」。
> 禁止：静默失败、只报"失败了"、把异常直接抛给用户。

### 7.1 失败矩阵（17 种）

| 环节 | 失败 | 用户看到 | 系统动作 | 人工兜底 |
|---|---|---|---|---|
| 连接 | 密码错 | 「密码不对，去控制台重置」 | 提供「自动重置并重装」（需云写权限）| 控制台重置 |
| 连接 | 22 端口不通 | 「连不上 22 端口，可能没开机或防火墙挡了」 | 重试 1 次后中止 | 查安全组/实例状态 |
| 连接 | 只允许密钥登录 | 「这台不接受密码登录，请改用私钥」 | 中止 | 换私钥重试 |
| 连接 | 私钥格式错 | 「私钥格式不对，应为 OpenSSH 或 PEM」 | 中止 | 重新导出 |
| 下载 | 所有镜像失败 | 「四个源都下不动，可能是网络问题」 | 列出试过的源 | 手动上传包 |
| 安装 | 架构不支持 | 「这台是 armv7，暂不支持」 | 中止，不留残留 | 换机器 |
| 安装 | 磁盘满 | 「服务器磁盘空间不足」 | 中止 | 清理后重试 |
| 安装 | 超过 15 分钟 | 「安装超时，已中止」 | 标记 `timeout` | 看原始输出 |
| 启动 | sing-box 起不来 | 「装好了但服务没起来」 | 节点标不可用，**不进订阅** | 看原始输出 |
| 端口 | 云防火墙未放行 | 「端口没放行」 | 腾讯云自动开；其他给指引 | 控制台放行 |
| 端口 | 仍不通 | 「端口仍不通」 | 标 `port`，**不上架订阅** | 查网络 ACL |
| 角色 | 国内机选出口 | 「这台在国内，翻不了墙，建议改为中转」 | 标 `role_mismatch`，不推荐使用 | 改角色重装 |
| **被墙** | **端口通但连不上/间歇超时** | **「这台可能被墙了」** | **标 `blocked`，保留节点** | **云控制台换 IP + 改 DNS** |
| **主控** | **admin 重启，任务丢失** | **「安装任务已中断，请重试」** | **前端检测 job 不存在即提示** | **重新点一次安装** |
| **订阅** | **token 泄露** | **「已作废旧订阅」** | **旧 token 立即 404，二维码重绘** | **换 UUID 可踢掉已连设备** |
| 粘链接 | 格式非法 | 「链接缺少 pbk」 | 拒绝，不改动现有订阅 | 重新复制 |
| 订阅 | 生成失败 | 「订阅暂时不可用，正在使用上一次的」 | **回滚到上一次可用订阅** | 查 Caddy 日志 |

### 7.2 回滚原则

1. **订阅原子更新**：新订阅成功才替换，失败保留旧的
2. **节点只增不删**：安装失败不产生半成品节点
3. **配置可回退**：改前备份，1 条命令还原
4. **不做自动删除**：任何自动流程都不删用户已有节点

### 7.3 降级路径

| 正常路径 | 降级 1 | 降级 2 |
|---|---|---|
| 密码安装 | 私钥安装 | 手动粘贴安装命令 |
| 自动开端口（腾讯云）| 提示手动开 | — |
| 镜像下载 | 换 4 个源 | 手动上传包 |
| 自动自测 | 只测端口 | 人工看日志 |

## 8. 数据与状态

节点记录新增字段：

| 字段 | 取值 | 说明 |
|---|---|---|
| `role` | `exit` / `relay` | 出口 / 中转 |
| `source` | `builtin` / `external` | 自建 / 粘链接 |
| `health` | `ok` / `port` / `tls` / `proxy` / `role_mismatch` / `landing` / `blocked` / `timeout` / `unknown` | 自测结果；`landing` 表示中转入口通但连不上落地；外部节点恒为 `unknown` |
| `exit_ip` | IPv4 或空 | 仅出口节点有值 |

状态机：

```
待安装 → 安装中 → 已安装 → 自测中 → 可用（进订阅）
                    ↘ 失败（reason）→ 不进订阅，保留记录
                    ↘ 超时 → timeout，保留记录
中转（relay）→ 自测通过 → 保存但**不进订阅**
```

## 9. 指标（v1.1 改为过程指标）

| 指标 | 目标 | 测量方式 |
|---|---|---|
| 失败可定位率 | **100%**（每条失败都有环节 + 下一步）| 人工抽查文案 |
| 假绿灯数 | **0**（外部节点不得显示在线）| 检查 UI |
| 单台安装耗时 | 海外 ≤2 分钟 / 国内 ≤8 分钟 | 计时 |
| 订阅可用率 | ≥99%（7 天）| 探活记录 |
| 误操作导致断线次数 | 0 | 事件记录 |
| 幂等违规 | 0（重装不产生重复节点）| 连续装两次 |

> 原"首次安装成功率 ≥80%"已删除：4 台机器算不出 80%，样本不足。

## 10. 依赖与风险

| 项 | 说明 | 应对 |

## 11. 已知缺口（写出来，避免被当成"已支持"）

| 缺口 | 影响 | 什么时候补 |
|---|---|---|
| **权限模型** | 现在只有一层 Basic Auth：谁能加/删/看，无区分 | 给别人用之前 |
| **多用户配额** | 无按人限速/限量 | 给别人用之前 |
| **任务恢复** | admin 重启丢任务，只能重来（D3）| 二期 |
| **真实连接验证** | 探活是握手不是真实流量，绿灯有假阳性（内部节点也可能误报）| 有需要时 |
| **中转跳板（T3）** | 只做了"中转节点保存"，没做链式转发 | 需要低延迟时 |

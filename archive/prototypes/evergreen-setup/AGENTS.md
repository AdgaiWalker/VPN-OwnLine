# 长青 Web 原型工作约束

## 当前范围

- 用户已确认中文普通 Web 页面，不使用手机外框、设备切换、模拟键盘、状态栏或自定义触控光标。字段保持“用户名”“密码”，不要自行改名。
- 保持浅纸色与深蓝、四项任务全部可见、每次仅展开一个完整任务。公网 IP、用户名、密码同属“连接服务器”，不做逐字段向导。
- 首选 SSH；私钥和 SSH 端口按需展开。腾讯云授权位于表单下方，厂商控制台帮助与云 API 授权分开。
- 此处仅是独立前端原型。连接、安装、云发现、账号与订阅均为演示，不访问真实 SSH/云 API、不自动打开本机客户端、不把模拟结果报告为真实完成。密码和私钥只在内存中，不写日志或持久存储。
- 客户端按钮使用 Shadowrocket、Clash、FL Clash；按真实浏览器平台选择。完成仅是当前浏览器会话的用户确认，复制链接独立可用；不宣称稳定设备识别或跨设备同步。

## 文件与实现边界

- 应用入口：[src/App.tsx](src/App.tsx)；主要交互：[src/Prototype.tsx](src/Prototype.tsx)；样式：[src/prototype.css](src/prototype.css)；网页弹窗：[src/WebDialog.tsx](src/WebDialog.tsx)。原生 input / textarea、页面滚动及 Radix 弹窗是当前实现。
- 本目录不是产品仓库，也不是线上代码副本；实际产品只在工作区的 `仓库/` 开发。不要把原型的 React/Vite 依赖视为生产技术栈要求。
- 当前仅保留普通 Web 实现；旧手机运行时、资源、专用测试和哈希保护脚本已移出活动目录，恢复资料在 `artifacts/历史原型-20261101.tar.gz`。不得重新引入手机模拟，除非用户明确要求。
- 当前截图为 `artifacts/browser-web-setup.png`，视觉来源为 `artifacts/source-selected.png`；早期截图只在历史包内，不要求保持旧截图散文件路径。

## 验证与交付

- 修改后按影响范围运行 `npm run build`（含 TypeScript 检查），在浏览器验证相关交互；涉及静态打包时运行 `npm run test:sites`；文档整理不虚构新 UI/生产验收结果。
- 开发入口为 `http://127.0.0.1:4173/`。Codex Desktop 中由代理启动并打开现有预览，不重复启动服务；只有本机服务运行时该地址才可用。
- 验收证据记录在[design-qa.md](design-qa.md)，保留历史失败及修正记录；真实设备、SSH、云账号及生产验证另行执行。
- 未收到明确指令，不推送、发布、部署、购买资源或操作真实服务器。公开前检查凭据与敏感内容。

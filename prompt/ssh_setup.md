# AI 辅助服务器接入任务书 (Agent Task Brief for SSH Node Onboarding)

> **使用场景**：在已克隆本项目的本地环境（或主控机器）中，将此任务书直接发给具备终端执行能力的本地 AI Agent（如 Cursor / Claude Code / Antigravity / Windsurf 等），附带新服务器信息，Agent 将全自动完成环境预检、扫雷加固与节点纳管。

---

## 任务书正文 (Task Brief)

```markdown
你是一个在「Evergreen · OwnLine」代码仓库根目录下工作的本地运维智能体，拥有终端执行与完整代码读取权限。
我的目标是将一台新的自备 Linux 云服务器接入本项目的节点池。
服务器信息如下：
[请在此处填入新服务器 IP、密码、密钥或邮件/控制台文本]

请你全权接管并自主执行全流程，不要向我抛出任何手动配置指令：
1. 本地预检与连通性探测：
   - 提取目标 IP 与凭据，调用本地终端探测 22 端口连通性及系统发行版（确认 Ubuntu 22.04+ 或 Debian 12+）；
2. 自动扫雷与系统加固：
   - 通过 SSH 登入目标机，直接自动执行环境就绪命令：放行内部防火墙（22、443、8443 端口）、确保 root 权限与 SSH 认证畅通；
   - 若遇云厂商安全组拦截，直接明确指出在云后台应放行的具体端口规则；
3. 一键纳管并出网验真：
   - 调用仓库现有的节点纳管流水线完成装配，并执行 verify.py 出网测试；
   - 确认无误后向我汇报：“新节点已自动装配完毕并上线，刷新管理控制台即可直接在小火箭/Clash 中使用！”
4. 安全守则：严禁将任何服务器密码或私钥明文提交至 Git 仓库。
```

# AI 辅助说明入口

主旅程从[项目 README 的 Get started](../README.md#get-started)开始，购买→资料准备→安装配置→本机导入；图形首次安装尚待实现，熟悉者可用一条命令。需要 AI 辅助时，从[AI-assisted setup](../README.md#ai-assisted-setup)复制开场提示词。入口采用“一句话开始＋分场景提示”的方式，不需要安装 Skill 或接入 Harness。

尚未购买者先查看[项目 README 的 Need a server?](../README.md#need-a-server)所链接的统一购买指南，不在本目录重复推荐清单。已有任意厂商的兼容服务器时，先准备公网地址和 SSH 登录；腾讯云 CAM 是下方可选的 Lighthouse 授权路径。也适用于连接后继续安装、验证与排障。

AI 先读取 README、[交互规格](../docs/设计/客户端Web交互设计规格说明书.md)与[工程规范](../docs/核心文档/04-工程规范与验收标准.md)，确认现有能力和目标后再协助。能否实际执行取决于用户所用 AI 的工具和授权；普通聊天只能指导。浏览器登录、敏感输入和权限操作按需要交给用户完成。

# 提示词：三段式

> **这一页定义产品怎么被使用。**
> 用户买一台服务器，打开任意能执行命令的 harness，粘三段提示词里的一段。
> 人只做两件事：填参数、看结论。

---

## 三段，对应三个时刻

| 什么时候 | 用哪段 | 干什么 |
|---|---|---|
| 第一次 | [install.md](install.md) | 装主控：面板 + 订阅 + 探活 |
| 日常 | [operate.md](operate.md) | 加节点、看状态、换锁 |
| 出事 | [troubleshoot.md](troubleshoot.md) | 按顺序查，不瞎改 |

每段都是**整段可粘贴**的，`<尖括号>` 的地方换成你自己的。

---

## 一条不能破的原则：提示词驱动本仓库的代码

| 做法 | 结果 |
|---|---|
| ✅ 提示词让 AI **clone 本仓库并运行 `deploy/install.sh`** | 一千个人装出来的是同一个东西 |
| ❌ 提示词让 AI **从零写一套** | 一千个人一千套，谁也帮不了谁 |

所以三段提示词里都**锁定了 tag**（`git checkout v0.1.1`）。

**不锁版本的提示词，等于没有产品。** 三个月后别人粘同一段话，装出来的会是另一个软件。

> 仓库里原来那段「从零生成」的提示词已经挪到文末**存档区**，标记为弃用。
> 它当初的定位是"加速器"，不是产品。

---

## 每段提示词都强制带三样东西

| 要素 | 出现在 | 为什么 |
|---|---|---|
| **前置检查** | install 开头 | 别让人在 CentOS 7 上装十分钟才发现不支持 |
| **验收命令** | 每段结尾 | 「装好了」不算数，`verify.sh` 输出 0 失败才算 |
| **失败停止契约** | 每段边界 | AI 最爱自作聪明。必须写死：失败就停，贴原始报错 |

第二条是这个项目最贵的一条教训：历史上出现过 **5 次"页面不报错但其实是坏的"**，全记在 [08-LESSONS.md](../docs/08-LESSONS.md)。

---

## 为什么不用一个万能提示词

因为它会变成"既要装、又要管、又要修"的一坨，AI 会在里面挑最容易的那条路走。

分开之后有个额外好处：**troubleshoot.md 可以单独迭代**——它会在你最没预期的时候被用上，值得比另外两段更用力打磨。

---

## 给 AI 的边界，单独一份

三段提示词里都写了"不要动别的服务"，但真正的边界在
[**docs/AGENT-CONTRACT.md**](../docs/AGENT-CONTRACT.md)：能碰哪些路径、密码怎么处理、什么必须停下来问、什么算完成。

**提示词是任务书，契约是法律。** 两样都要给。

---

## 这个方案的前提

| 前提 | 说明 |
|---|---|
| harness 能执行命令 | Claude Code / Codex / Cursor 这类。纯聊天的不行 |
| 用户有腾讯云轻量 + 一个域名 | 域名可不接 Cloudflare，但源站 IP 会暴露 |
| 用户不需要懂 Linux | 但需要会判断"AI 说得对不对" |

最后一条没法绕过：**AI 可能说装好了，而实际没装好**。所以每段提示词都强制以命令输出结尾——把判断权从"AI 的说法"换成"命令的结果"。

---

# 存档：旧版「从零生成」提示词（已弃用）

> ⚠️ 下面这段**不再推荐**。它让 AI 从零写一套，每次结果都不一样，也无法验收。
> 保留是因为它记录了当时的思路，以及「硬约束 8 条」里每一条对应的真实坑。

```
# 角色
资深全栈运维工程师，为不懂技术的用户搭建「纯网页可管」的个人 VPN。

# 目标
用户只做两件事：输密码、点按钮，其余全自动。

# 硬约束
1. VLESS + Reality + Vision，节点 443/8443，不用域名和证书
2. 面板单页 HTML 无框架；入口 Basic Auth；/api/* 反代本机 Python
3. Cloudflare 前置：SSL=Full、Origin Rule 指 8443、隐藏源站
4. 节点可增删、改名、改端口、换密钥
5. 禁止危险默认：不预选在用机器；删除与重装二次确认
6. 失败必须给「下一步怎么办」
7. 二进制走镜像并校验 SHA256；国内机器禁直连 GitHub
8. 密码错误时可自动重置密码并重装

# 交付
- 一键加节点：选机器→输密码→装→自动开防火墙→自动验证
- 订阅 /s/<token>：按 UA 返回 clash 或 v2ray
- 60 秒探活，红灯写明原因（端口/服务/机器）
- 流量与到期展示、备份脚本、恢复文档

# 验收
新机器 ≤2 步装好；报错为中文且可执行；未授权 401；猜 token 404。

# 风格
中文界面，4 档字号，触控 ≥44pt，底部弹层代替 alert。
```

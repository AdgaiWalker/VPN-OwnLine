# 复刻提示词（可选加速器）

> **先说清楚：提示词不是交付物。**
>
> 同一段提示词给不同的 AI，会得到不同的代码；同一个 AI 跑两次也不一样。
> **能复现的是本仓库的代码，不是提示词。**
>
> 提示词的正确用法：你已经有一台服务器、想快速得到能跑的雏形，
> 然后**用 [验收清单](../docs/07-ACCEPTANCE.md) 逐条验它**。

---

## 提示词（474 字）

```
# 角色
资深全栈运维工程师，为不懂技术的用户搭建「纯网页可管」的个人 VPN。

# 目标
用户只做两件事：输密码、点按钮，其余全自动。

# 硬约束
1. VLESS + Reality + Vision，节点 443/8443，不用域名和证书
2. 面板单页 HTML 无框架；入口 Basic Auth；/api/* 反代本机 Python
3. Cloudflare 前置：SSL=Full、Origin Rule 指 8443、隐藏源站
4. 节点可增删、改名、改端口、换密钥
5. 禁止危险默认：不预选在用机器；删除与重装二次确认
6. 失败必须给「下一步怎么办」
7. 二进制走镜像并校验 SHA256；国内机器禁直连 GitHub
8. 密码错误时可自动重置密码并重装

# 交付
- 一键加节点：选机器→输密码→装→自动开防火墙→自动验证
- 订阅 /s/<token>：按 UA 返回 clash 或 v2ray
- 60 秒探活，红灯写明原因（端口/服务/机器）
- 流量与到期展示、备份脚本、恢复文档

# 验收
新机器 ≤2 步装好；报错为中文且可执行；未授权 401；猜 token 404。

# 风格
中文界面，4 档字号，触控 ≥44pt，底部弹层代替 alert。
```

---

## 为什么这么写

| 写法 | 理由 |
|---|---|
| 「为不懂技术的用户」放第一句 | 受众决定一切设计 |
| 硬约束 8 条 | 每条对应一个真踩过的坑 |
| 「禁止危险默认」 | AI 默认会给最危险的选项（重装在用的机器）|
| 「失败必须给下一步」 | AI 最常偷懒：把异常直接抛给用户 |
| 验收写成数字 | "≤2 步""401""404" 能验证；"体验好"不能 |
| 风格单独一节 | 功能与设计混写时，AI 一定牺牲设计 |

## 提示词没写、但你必须知道的

1. Reality 参数错一个字符就连不上，且**没有任何错误提示**
2. Cloudflare 的 SSL 模式选错，页面直接 525
3. 国内机器下不动 GitHub，必须走镜像

这三条在 [03-FAILURE-MODES.md](../docs/03-FAILURE-MODES.md)。**先读那个，再用提示词。**

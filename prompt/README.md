# AI 辅助说明入口

新手统一从[项目 README 的 AI-assisted setup](../README.md#ai-assisted-setup)复制开场提示词。入口采用“一句话开始＋分场景提示”的方式，不需要安装 Skill 或接入 Harness。

适用情况：用户已经买了腾讯云服务器，却不知道在哪里查看公网地址、如何准备 SSH 登录、怎样配置 CAM 子账号，或者连接后不知道怎样继续安装和验证。

AI 先读取 README、[交互规格](../docs/设计/客户端Web交互设计规格说明书.md)与[工程规范](../docs/核心文档/04-工程规范与验收标准.md)，确认现有能力和目标后再协助。能否实际执行取决于用户所用 AI 的工具和授权；普通聊天只能指导。浏览器登录、敏感输入和权限操作按需要交给用户完成。

## 旧三段任务书

| 文件 | 用途 | 使用状态 |
|---|---|---|
| [install.md](install.md) | 首次部署步骤 | 历史任务参考，不是新手统一入口 |
| [operate.md](operate.md) | 日常 API 操作 | 历史任务参考；接口与副作用以当前代码和新规格核对为准 |
| [troubleshoot.md](troubleshoot.md) | 排障顺序 | 历史任务参考，先核对当前服务与数据路径 |

这些旧文件可能保留过去的版本、域名、服务、路径和安全处理方式，不能整段当成当前可靠的执行指令。特别是完整远程卸载、只读连接检查等新设计，不能因旧任务书中出现相关描述就声称已经实现。

新手可复制入口及分场景提示词只维护在 README，避免多份提示词分叉。这里不安装外部参考项目、不生成 AI 运行时，也不自动操作任何云账号或服务器。

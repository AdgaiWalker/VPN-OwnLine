        系统与端口：空白 Ubuntu 22.04+ 或 Debian 12+（x86_64 / arm64，支持 root 或云商默认免密 sudo 账号如 ubuntu，且有公网 IPv4）；在云防火墙放行 SSH 端口（默认 22）、80/TCP（自动申请 HTTPS 证书必需：默认 sslip.io 与自定义域名均需放行）、8443/TCP（管理后台与订阅分发）、443/TCP（VLESS Reality 主通道）、443/UDP（Hysteria2 晚高峰高速通道）。

        双机中转加速（4K / 跨境办公进阶）：加购 1 台国内轻量服务器（如北京/广州），通过 8443 端口直通海外落地机改善晚高峰丢包。

        请协助我用 Evergreen · OwnLine 的跨平台本地引擎（macOS / Windows / Linux），从 0 完成专属节点配置（规范见 skills/ownline-local/SKILL.md，选型与准备清单见 web/src/data/onboarding.json）：
1. 在仓库根目录运行 python3 ownline.py doctor --json 检查与自举环境（Windows 可用 py -3 ownline.py 或 python ownline.py；图形回退入口为「启动安装.command」/「启动安装.bat」或 ownline.py ui）。如我尚未购买服务器，先读取 web/src/data/onboarding.json 为我对比方案与必开端口（Ubuntu 22.04+ 或 Debian 12+，放行 SSH、80/TCP、8443/TCP、443/TCP、443/UDP）。
2. 需要 SSH、腾讯云只读 API、Webshare 家宽或面板密码时，调用 ownline.py vault request --slot <ssh|tencent_api|webshare_isp|panel_auth> 弹起本机安全输入卡（无桌面环境自动退回终端隐身输入），让我本人在本地页面输入，严禁让我在对话中发送任何明文凭据。
3. 拿到句柄后先用 ownline.py check --vault-handle 预检（首次连接请我核对 SSH 指纹）并通过 ownline.py install 完成首装，再按需用 ownline.py apply 串联改密、Webshare 静态住宅与中转扩容验真。
4. 交付后清理本机句柄（ownline.py vault clear --json），告知管理后台地址并提醒仅靠本机内存交付初始密码；严禁索取、复制或输出密码、私钥、密钥、订阅链接或含凭据截图。

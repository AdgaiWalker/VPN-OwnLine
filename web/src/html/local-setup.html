Evergreen OwnLineMac 本地安装

连接你的服务器

从这台 Mac 直接连接你的 Linux 服务器。登录信息仅在本机内存中使用。

服务器要求和端口

使用空白 Ubuntu 22.04+ / Debian 12+ 服务器和 root 账号。请先在云控制台放行 SSH 端口，以及 80/TCP、8443/TCP、443/TCP 和 443/UDP。

安装页面尚未就绪。如果此提示持续显示，请启用 JavaScript，再从 Mac 的启动入口打开。

SSH 登录选项

选择腾讯云服务器

使用腾讯云只读 API 密钥读取实例。选中后，使用该服务器的 SSH 密码或私钥连接。

选择实例

    确认安装到这台服务器

    连接检查已通过。确认后会在这台服务器上配置代理、管理后台和所需端口。

    安装进度

    安装期间请保持 Mac 和启动窗口运行。

    安装与服务端验收通过

    Mac 已验证管理入口的 HTTPS、登录和订阅；目标服务器已验证代理出网。手机或桌面客户端导入仍需你实际确认。

    打开管理后台

    账号：admin

    请保存密码并在管理后台完成首次改密。关闭本地服务后，本页交付信息会失效。

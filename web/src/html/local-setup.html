        查看完整任务书与端口说明 
        请协助我用 Evergreen · OwnLine 的本机引擎（macOS / Windows / Linux），为一台我确认的新 Linux 服务器创建首个节点。
1. 在仓库根目录运行 python3 ownline.py doctor --json 检查环境（图形回退入口为「启动安装.command」/「启动安装.bat」或 python3 ownline.py ui）。使用空白 Ubuntu 22.04+ 或 Debian 12+ 和 root 账号。
2. 需要 SSH 凭据时，调用 python3 ownline.py vault request --slot ssh 打开本机盲签输入页，让我本人在本地页面输入密码或粘贴私钥，不要让我把明文发进对话。
3. 使用盲签返回的句柄调用 python3 ownline.py check --vault-handle，提示我核对 SSH 指纹。检查通过后，让我核实目标并确认创建。
4. 等待页面验收，告诉我如何打开管理后台并首次改密。不要索取、复制或输出密码、私钥、密钥、订阅链接或包含凭据的截图。

        使用空白 Ubuntu 22.04+ 或 Debian 12+ 和 root 账号。在云安全组放行 SSH 端口、8443/TCP、443/TCP 和 443/UDP（使用域名自动签发 HTTPS 证书时另放行 80/TCP）。

        凭据仅在本机内存中使用。SSH 凭据用于连接你的服务器，云 API 密钥仅用于直接向腾讯云读取实例。

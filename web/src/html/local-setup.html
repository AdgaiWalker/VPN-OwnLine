连接设置（非 root 账号或非 22 端口）

用只读 API 密钥读取你的轻量应用服务器或 CVM 实例。

选择实例

    首次连接 · 锁定服务器指纹

    确认上方服务器 IP 与你购买的一致后，点击下方按钮锁定这台机器的唯一身份指纹；后续每次连接都会自动比对防篡改。

    确认创建节点

    将在这台服务器上配置代理、管理后台和所需端口。

    正在创建节点

    安装期间请保持本机和启动窗口运行。

    节点已创建

    服务端验收已通过。登录后台改密，再导入客户端。

    建议先复制保存或在浏览器保存密码；安装完毕点击页脚「关闭本地服务」即可清空内存凭据。

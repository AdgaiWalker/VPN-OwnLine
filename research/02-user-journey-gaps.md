# 02 - 用户旅程卡点图谱 (User Journey & Friction Gaps)

> **版本**：v1.0.0 · 2026-11-09  
> **研究对象**：非技术用户在自建出海网络全流程中的行为、心理困惑与客观摩擦死穴  
> **制定原则**：彻底消灭“工程师视角的傲慢”，以显微镜审视非技术小白在真实世界碰壁的每一个具体节点。

---

## 一、 用户旅程全景矩阵 (Journey Map Overview)

全流程分为四个线性阶段，每个阶段均包含 **用户真实行为**、**用户心理困惑** 以及 **导致流程暴毙的客观卡点**：

```
┌──────────────┐     ┌──────────────┐     ┌──────────────┐     ┌──────────────┐
│  阶段 1:     │     │  阶段 2:     │     │  阶段 3:     │     │  阶段 4:     │

└──────────────┘     └──────────────┘     └──────────────┘     └──────────────┘
```

## 二、 阶段逐层深剖 (Phase-by-Phase Friction Analysis)

### 阶段 1：认知建立与云主机选购 (Discovery & Server Purchase)

| 维度 | 真实剖析 |
| :--- | :--- |
| **用户的真实动作** | 打开各大云厂商（腾讯云/阿里云/AWS）控制台或选购页，准备掏钱买一台机器。 |
| **用户的心理困惑** | 1. “轻量云（Lighthouse）和 CVM 云服务器有啥区别？该买哪个？”<br>2. “香港、新加坡、硅谷、东京，到底买哪里的看剧快、登 ChatGPT 不会被封？”<br>3. “操作系统选 Ubuntu 还是 Debian？选哪个版本才不会缺依赖报错？”<br>4. “按流量计费还是按带宽计费？会不会不知不觉欠费几千块？” |
| **客观摩擦死穴 (暴毙点)** | **死穴 1.1（买错内网/大陆机器）**：新手误买了国内大陆地域（如广州/北京），装完发现根本无法出海。<br>**死穴 1.2（系统架构不兼容）**：误选了带有宝塔、WordPress 等定制镜像，或选了旧版 CentOS，导致底层系统服务无法通过 Systemd 正常启动。 |

---

### 阶段 2：授权接入与资产信息收集 (Authorization & Asset Ingestion)

| 维度 | 真实剖析 |
| :--- | :--- |
| **用户的真实动作** | 买完机器后，试图把主机信息（IP/密码/密钥）交给装配系统。 |
| **用户的心理困惑** | 1. “公网 IP 在哪里看？内网 IP（10.0.x.x）行不行？”<br>2. “我买机器的时候根本没让设 root 密码，密码去哪找？”<br>3. “如果要用腾讯云 API，CAM 子账号是什么鬼？我把 SecretId/Key 填进去，我的腾讯云会不会被盗？” |
| **客观摩擦死穴 (暴毙点)** | **死穴 2.1（云安全组默认封锁）**：腾讯云默认模板仅开通 `22` 端口，`80, 443, 8443` 全部处于阻断状态，用户在这一步毫不知情。<br>**死穴 2.2（CAM 权限过大失控）**：用户不知道如何设置最小权限，误赋予 `AdministratorAccess` 导致巨大安全隐患；或权限过小导致 API 无法读取实例列表。 |

---

### 阶段 3：一键装配与独立面板自举 (Execution & Self-Bootstrapping)

| 维度 | 真实剖析 |
| :--- | :--- |
| **用户的真实动作** | 打开控制台网页终端，执行安装命令，等待进度条跑完并获取独立管理 URL。 |
| **用户的心理困惑** | 1. “这黑乎乎的终端跑了一大堆看不懂的代码，现在是卡死了还是在正常跑？”<br>2. “终端打印出来一个 `https://43.x.x.x:8443`，为什么浏览器提示‘您的连接不是私密连接’？”<br>3. “新生成的网站，真的是我一个人的吗？我之后每次都要来这里看吗？” |
| **客观摩擦死穴 (暴毙点)** | **死穴 3.1（国内网络依赖拉取超时）**：在国内机器或跨海直连严重恶化的网络下，从 GitHub 拉取 `sing-box` 发行包或从国外源下载 APT 依赖直接超时退出。<br>**死穴 3.2（去中心化自举断裂）**：传统加节点仅在后台起转发进程，未在目标机器启动独立 Web 面板和 Caddy 反代，用户无法获得独立的私有管理入口。 |

---

### 阶段 4：客户端导入与日常使用 (Client Import & Daily Usage)

| 维度 | 真实剖析 |
| :--- | :--- |
| **用户的真实动作** | 在手机或电脑上安装代理客户端，导入新生成的专属订阅，开启加速。 |
| **用户的心理困惑** | 1. “为什么中国区 App Store 根本搜不到 Shadowrocket（小火箭）？”<br>2. “美区 Apple ID 去哪弄？会不会封我的 iPhone？会不会跟我的 iCloud 冲突？”<br>3. “在微信里点开别人发给我的网址，为什么什么都点不动？”<br>4. “晚上 9 点看视频卡了，我是该重装呢，还是系统本来就这样？” |
| **客观摩擦死穴 (暴毙点)** | **死穴 4.1（下载李鬼恶意软件）**：用户在百度搜出山寨收费高仿小火箭，被骗取钱财甚至泄露隐私。<br>**死穴 4.2（微信内嵌浏览器拦截）**：微信沙箱禁止非标端口访问，且拦截 `shadowrocket://` 深链接唤起，导致点击“一键连接本机”毫无反应。<br>**死穴 4.3（需求不会表达导致功能闲置）**：晚高峰遇到链路丢包，用户不知道可以开启 HY2 或中转专线，默默忍受卡顿甚至放弃使用。 |

## 三、 卡点消灭技术映射表 (Gap-to-Solution Matrix)

| 卡点代号 | 摩擦卡点描述 | 我们的核心消灭机制 |
| :---: | :--- | :--- |
| **GAP-01** | 云安全组 80/443/8443 默认墙阻断 | **前置防火墙放行规则验证** + 引导/Agent 自动化调用 API 一键放行端口 |
| **GAP-02** | 依赖下载遇跨海丢包超时中断 | **智能握手测速** + 动态自动回退至**清华 Tuna 镜像源与 GitHub 加速通道** |
| **GAP-03** | 国区 App Store 无法下载正版小火箭 | 面板内嵌**免外币美区 Apple ID 获取通道** + 3 步纯 App Store 换号安全指引 |
| **GAP-04** | 微信内无法唤起客户端深链接 | 前端 **`#wx-tip` 微信智能环境嗅探**，强提醒跳出至 Safari / Chrome 浏览器 |
| **GAP-05** | 新服务器无法独立交付私有 URL | 打包 Caddy 2.10 网关 + admin.py 核心，新机本地完成自签名/合法 TLS 独立自举 |
| **GAP-06** | 高级功能平铺导致用户盲目闲置 | **双向唤醒机制**：基于真实测速主动弹出优化胶囊；基于场景提示词实现意图映射 |

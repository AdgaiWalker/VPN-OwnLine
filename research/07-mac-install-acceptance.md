## 未关闭的问题与边界

- 后台自动健康状态异常：健康检查提示探活数据未生成；手动测速显示 All Nodes Operational，但重载后再次显示 Checking / Unverified。手动测速有效不代表后台定时探活正常，根因和修复尚未完成。
- 安装期间只有通用等待提示，缺少当前阶段及耗时信息；本轮没有可归因的分阶段计时，不能将用户感受到的慢直接归因于某个下载源。
- 未配置腾讯云 API 凭据，因此云流量快照不可用。本轮没有实测计费用量采集或超额停机，不能声称费用保护已验证。
- 小火箭显示中国国旗的原因尚未定位。独立协议测试证明新节点出口匹配测试机；这不解释国旗来源，也不证明用户截图中的浏览器请求走了新节点。
- 未执行 Windows、Android、实体 iPhone 的完整独立验收，未执行真实加密私钥首装、安装断网/断电、失败后重试、重启恢复及长时间稳定性测试；已有对应离线覆盖不能替代这些实机测试。
- 本轮没有重新购买第二台服务器验证添加节点，也没有对用户既有生产节点注入故障。

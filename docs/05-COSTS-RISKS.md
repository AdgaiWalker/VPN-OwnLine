# 成本、风险与合规

**动手之前先读这一页。** 自建不等于免费，也不等于安全。

---

## 成本

| 项目 | 价格 | 备注 |
|---|---|---|
| 主控服务器 | $5~10/月 | 1 核 1G 够用；只在加节点时忙 |
| 节点服务器 | $5~10/月/台 | 建议 ≥2 台，不同机房 |
| 域名 | $10/年 | 便宜的 `.xyz` 即可 |
| Cloudflare | 免费 | 免费套餐够用 |
| 流量 | 多数套餐含 500G~1T/月 | 看视频会很快用完 |

**一年大概 $150~250（两节点）**。对比机场（$3~10/月）并不便宜——自建买的是**独占和不被审查**。

---

## 风险

### 被封 IP（高概率）

- 表现：节点突然全红，但服务器 SSH 正常
- 处理：云控制台换公网 IP + 改一条 DNS
- 频率：热门机房可能几个月一次，冷门机房一年一次

### 机房被整段封（中概率）

- 表现：换 IP 也没用
- 处理：换机房/换服务商
- 教训：**别在同一家一次买满**，留一个备用

### 订阅链接泄露（人为）

- 表现：流量跑得比用的快
- 处理：轮换 token；换节点 UUID

### 云账号被入侵（低概率，后果最重）

- 若给了写权限，攻击者能删掉所有机器
- 处理：主账号开 MFA；子账号只给必要权限；密钥文件 600

## 合规

**这一节不是法律建议，请自行判断。**

- 在中国大陆，未经批准自建跨境网络通道用于经营，可能涉及违法
- 个人自用与"提供给他人使用"在法律上性质不同，**分享订阅链接给对方使用需自行评估**
- 不同国家/地区规定差异很大
- 企业环境使用请走正规专线

**本仓库只提供技术实现，不对使用场景的合法性负责。**

---

## 什么时候该放弃自建

- 你只想安安静静上个网，不想每月花两小时运维 → 用商业服务
- 你只有一台设备、一个节点 → 直接装客户端，不要这套系统
- 你无法承担"哪天全线不通"的后果 → 至少准备两条独立线路

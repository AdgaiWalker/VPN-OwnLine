## 1. 设计目标与边界

### 1.1 产品定位与使用者

产品以**让用户用上自己的专线**为核心，是服务器主人自用的远程装配与订阅交付辅助工具。完整旅程为“购买服务器 → 准备公网地址与 SSH 登录资料 → 安装配置 → 导入本地客户端”，页面围绕用户当前下一步组织；AI 只作可选帮助，不是完成流程的前提。

目标是让用户通过管理网页连接自己的远程 Linux 或 Windows 电脑，查看检查结果并主动开始节点装配，再向小火箭、Clash、FL Clash 交付订阅。当前完整管理端首次安装仅支持受约束的空白 Linux；Windows 节点自动安装与已有节点接管仍待实现。

必须区分用户设备、用户自己的管理服务和目标服务器。首次尚无管理网页时，用户在腾讯云终端执行安装命令；外部 AI 仅为可选帮助。公共介绍页不收取或转发 SSH 密码、私钥或云密钥。用户自建管理网页后，授权资料只能在其自有服务使用；已存在的独立安装后台属于本地受控工具，不作为运营者公共入口上线。

既有三种对象：

| 对象 | 职责 |
|---|---|
| 用户设备 | iPhone、Android、Mac、Windows、Linux 上的浏览器与原生客户端；不是因访问网页就变成节点 |
| 管理服务所在服务器 | 提供网页、SSH 装配任务、订阅与状态管理；可以同时提供节点服务 |
| 目标节点电脑 | Linux 或 Windows；接受用户授权后的连接与节点装配，可能与 Linux 管理服务同机。Windows 自动装配尚待实现 |

本产品不接管原生客户端的流量转发、常用节点选择、自动优选或路由策略，不为这些功能增加模式、选择页或开关。后台既有装配机制与客户端原有能力不因此被宣称为新 Web 功能，也不在本次文档修订中被改写。

### 1.2 目标路径

主旅程按下列顺序组织，不作为四个常驻大面板或必须从头完成的身份问卷：

| 顺序 | 用户要完成的事 | 下一步依据 |
|---|---|---|
| 1 | 购买服务器 | 没有机器者先选购；已拥有服务器直接准备资料，不要求再购买 |
| 2 | 进入腾讯云控制台和目标服务器终端 | 可选 README 的现有 AI 提示词；敏感登录验证由用户完成 |
| 3 | 检查、确认目标、开始安装配置 | 目标服务器执行安装；交付经验证的管理地址和独立的网页登录信息 |
| 4 | 导入本地客户端 | 已有经验证服务者直接进入本机客户端导入；原生客户端完成实际连接 |

以下为各情况的行为规则。只根据已有资料、用户确认与真实服务/任务状态选择起点；没有云授权时不能推断用户未买服务器。

| 阶段或情况 | 用户操作 | 系统应完成的工作 |
|---|---|---|
| 尚无管理网页 | 在腾讯云控制台的目标服务器终端运行项目安装命令；AI 可选 | 目标是部署完整管理系统与本机节点，交付经过验证的管理地址及独立网页登录信息；不得向项目运营者提交服务器凭据 |
| 没有服务器 | 从 README 的 Need a server? 查看统一购买指南；按需使用 AI | 以实惠为主，区分付费、长期免费额度及限时试用；用户自行购买或激活 |
| 准备资料 | 使用腾讯云控制台及 README 中可选 AI 提示词 | 导航不等于授权；AI 无工具时只能引导，不自动代管或读取用户秘密 |
| 默认 SSH 接入 | 先填公网地址、用户名（默认 root）、密码或私钥，点击连接 | 不要求云账号授权；只读连接检查，展示机器、系统、兼容性及已有 sing-box 状态 |
| 可选腾讯云授权 | 在 SSH 区域下方选择腾讯云，从发现列表选一台 | 仅 Lighthouse 原生适配；辅助发现与云能力，不自动安装全部机器 |
| 尚未安装或缺少有效配置 | 查看检查结果，点击开始安装 | 下载适配包、配置、启动、验证并交付订阅 |
| 已有可兼容配置 | 查看接管范围，点击添加服务器 | 保留程序与配置，接入管理并生成订阅；需要写入控制权限时提前说明 |
| 已安装客户端 | 点击一次应用名 | 尝试唤起并传递适配后的订阅；系统与客户端确认由用户完成 |
| 未安装客户端 | 点击应用名；安装后回来再点击 | 提供下载兜底，保留原任务与订阅上下文 |
| 使用复制方式 | 点击复制链接 | 复制稳定订阅地址，失败时提供手动复制 |
| 日常维护 | 查看必要提示；确认会中断连接的修复 | 自动检查；按授权执行修复；记录可证实的结果 |
| 移除服务器 | 确认完整卸载影响 | 摘除全部关联节点，停止并清理已接管的 sing-box，保留管理网页和其他业务 |
| 备份与恢复 | 导出文件；可选配置异地目标；恢复前确认 | 如实展示备份状态、覆盖影响和恢复结果 |

登录沿用现有管理员认证，本轮不增加用户注册、亲友权限或多租户账号。原生客户端的系统授权、购买及连接确认仍需纳入旅程验证，不能算作本产品已自动完成。

### 1.3 范围与不做清单

本规格覆盖完整使用流程。**日常首页**依次展示客户端导入与复制链接、各服务器状态及真实用量、最近 2～3 条日志；详情和维护按需展开。首次无可用服务器时展示下一步，不让用户面对无效导入操作。

不增加：自研代理客户端、浏览器内连接开关、客户端节点优选与路由控制、应用市场、其他客户端推荐列表、客户端偏好设置页、协议或订阅格式选择器、跨设备偏好同步、用户自填 App Store 账号地区表单、自动购买服务器、邮件或 Telegram 通知配置。

**不接入 Harness 功能。** 允许首次由 AI 帮助运行现有部署流程，不代表产品增加 Harness、Agent 执行器、AI 调度平台或运行时。供研发 AI 阅读的实现约束与注释见 §10.7；供新手复制给自己 AI 的提示词统一放在项目 README，交互要求见 §10.8。

| D-42 | 清单完成依据分别为已有服务器的明确事实、用户确认进入所选目标终端或用户自有管理页的真实 SSH 检查、安装后的服务及交付验证、当前设备的用户确认；打开控制台不自动等于进入终端或完成安装。未知不显示已完成或未安装。 |
| D-43 | 前三项按目标服务器实际状态，客户端项按当前设备/订阅上下文处理；不跨设备同步“已导入”。清单可收起并从帮助重开，日常以导入为主；可选完成仅记录用户确认，不阻挡应用按钮和复制链接，也不伪装成系统检测到连接成功。 |

### 2.2 统一术语

- **Shadowrocket**：小火箭。讨论中的“Shadowsocks”按小火箭的口语误称处理；本文不新增 Shadowsocks 客户端支持。
- **FL Clash**：界面显示名，工程项目名为 FlClash。保持用户确认的按钮拼写。
- **Clash**：界面类别名。研发需为不同平台配置明确的发行版和兼容版本，不表示支持所有同名软件与历史分支。
- **外区账号**：中国大陆地区以外的 App Store 账号，不指设备所在地、界面语言或专线出口地区。
- **服务器与节点**：同一台物理服务器可生成多个协议节点；管理与卸载以服务器为对象，协议节点在详情中展开，不能当作多台机器。
- **资料准备**：找到目标实例、公网地址和真实 SSH 登录方式；打开控制台不等于完成登录或获得 API 授权，服务器 SSH 凭据也不是安装后交付的管理网页凭据。
- **AI 辅助说明**：用户从 README 复制任务给自己使用的 AI；既不是产品内聊天，也不是自动向外部 AI 转交 SSH 会话、云密钥或执行权限。
- **远程连接成功**：仅表示管理服务通过 SSH 读取到了目标服务器信息；不表示安装、节点验证或用户设备代理连接成功。
- **已接管**：用户已主动确认将该机的 sing-box 纳入本系统维护及完整卸载范围；只扫描发现或只读检查不等于已接管。
- **唤起**：浏览器尝试将导入链接交给应用。观察到页面进入后台仅是间接信号。
- **导入完成**：客户端实际读取并接受订阅。当前网页没有可靠的通用完成回执。
- **连接成功**：客户端完成连接且有相应验证证据；不能由点击、页面隐藏或导入动作推断；界面不使用含糊的“已连接” 同时指 SSH 与代理。

### 2.3 设计与能力的区别

网页能进行设备适配、构造导入链接、发起导航、观察自身可见性并提供下载链接。网页不能可靠枚举第三方已安装应用，也不能读取当前 App Store 账号地区。

因此，自动下载使用“未观察到应用唤起”的兜底规则，不将用户标记为“确定未安装”。规则属于用户接受的交互取舍，不承诺百分之百准确。浏览器能力依据见[安装检测说明](https://developer.chrome.com/docs/capabilities/get-installed-related-apps)。

交互和恢复约束：

- 自动更新能够证实的状态，不让用户为系统已知的前三项反复打勾。当前任务缺资料或遇到问题时，原因紧贴该项，主操作指向可继续的处理步骤，原始日志按需展开。
- 普通服务故障在原任务显示需要处理及相应修复；不抹掉“已有服务器”等事实让用户重新购买。暂时读不到状态显示未知并恢复查询，不伪造进度百分比或已完成。
- 任务运行、页面返回与非敏感输入按 §3.3、§5.5 恢复；清单只是这些状态的呈现，不另起安装任务，不在浏览器长期存储 SSH 凭据。
- 用户可以主动收起收起清单，帮助中以设置清单重新展开；收起不等于完成、取消或清除后台任务。服务可用时，清单不得阻挡客户端按钮和复制链接，最后确认不是使用前置。
- 前三项跟目标服务器走，第四项跟当前设备的导入任务走。在电脑确认完成不代表新打开的 iPhone 已导入；不能靠账号或服务端全局完成标记替手机打勾，不增加设备指纹或客户端偏好同步。没有本地明确记录时状态为未确认，不声称“未安装”。
- 已导入稳定订阅后的节点更新沿用客户端刷新规则，不因添加服务器就强迫重复导入。用户完成是自报确认，不作为后端已检测到设备连接的证据。
- 状态有可读文字、键盘可操作和明确焦点；动态更新遵循非打断式辅助朗读，不只靠颜色或勾形状表达。

## 5. 完整任务流程

### 5.1 首次部署与登录

- 用户先通过腾讯云控制台进入自己选择的目标服务器终端，使用现有安装命令；README AI 提示词可选。不建设单独的终端图文向导，公共介绍页不接收 SSH 密码、私钥或云账号密钥。
- AI 帮助定位服务器与终端；其读取屏幕或终端时可能看见敏感输出。登录验证、执行安装及保存初始密码由用户自己接手；不要求将任何密钥或密码发送到 AI 对话。
- 安装前检查机器与现有服务、说明影响并由用户主动确认。操作失败或终端断开时先检查实际状态，不盲目重装或覆盖其他业务。
- 首次部署完整管理系统和本机节点；已有管理页的添加服务器默认接入目标节点，不能为每台新增节点无条件重复部署管理系统。操作前显示将安装什么，遇到已有程序/配置按 §5.4 处理。
- 目标终端交付验证后的安全管理地址、管理用户名及新安装随机初始密码；首次登录后用户自行设置新密码，之后使用新密码登录。已有安装沿用现有凭据，不因重试重置。区分管理网页凭据与 SSH 凭据，不写普通日志、截图或公开链接；忘记管理密码时由用户在服务器终端恢复。
- 验证需分别检查服务状态、实际公网管理入口及订阅读取，包含证书校验、真实 HTTP 状态和目标响应；不能以本机 curl 请求完成代替外部可达性，更不能宣称客户端已经连接。安装完成但交付入口未验证时显示待处理的原因与下一步。
- 终端断线后先复查目标服务器和既有任务，报告真实状态；不能把浏览器返回或终端输出缺失当作安装成功，也不能自动创建重复安装任务。
- 使用现有管理员身份，不新增注册、社交登录或多用户系统；标准新安装的首次改密及终端重置已有隔离 Caddy 实测，腾讯云和生产环境尚未验收，旧安装配置不会自动改写。
- 登录后读取已有机器与任务：有可用节点直接导入；无服务器进入接入；已有任务则恢复任务状态。
- 尚未购买且管理网页也不存在时，从[项目 README 的 Need a server?](../../README.md#need-a-server)进入统一英文购买指南；该入口位于 AI-assisted setup 之前。网页不是选购的唯一入口，避免先买机器部署网页才能看到买机说明的循环。
- 已有管理网页时，仅在添加服务器区域放低强调 Need a server?，链接同一份指南；正常导入首屏不出现厂商卡片、排行榜、价格广告或购买按钮。
- 指南集中维护候选产品、官方入口、真实地区与成本核对方法；本规格、PRD、索引和 prompt 导航只链接，不复制推荐清单详情或活动价格。
- 以持续使用总成本比较候选，区分长期免费额度、限时试用和赠送额度；公网 IPv4、磁盘及出站流量可能单独计费。免费 VM 不等于完整部署零费用，不能承诺 Google/Oracle 身份审核宽松或无需验证。
- 默认准备 Ubuntu 22.04、x86_64、公网 IPv4、systemd 与管理权限；CPU/RAM 没有经过本项目基准验证的最低值。购买或免费资源激活由用户在官方渠道完成，AI 不代购、不自动升级付费账号；不合适的已有机器先解释差距，不擅自重装或要求重新购买。

### 5.2 默认 SSH 与可选腾讯云授权

### 5.7 移除服务器与完整卸载

移除对象是服务器，而不是某一条协议记录。确认摘要应列出：机器身份、受影响的全部订阅节点、会停止和清理的 sing-box、管理网页或其他必要共享组件的保留项；并说明云服务器和费用不会因此自动取消。

用户确认后执行：

1. 将该机全部关联节点移出本系统订阅，避免新拉取继续使用它；不承诺已缓存配置的客户端立即清除旧记录。
2. 停止代理服务，验证已停止；清理由本系统安装或接管的 sing-box 程序、配置、证书、临时包、独占服务与控制权限，以及能明确归属本项目的规则。
3. 原本已有、后被明确接管的 sing-box 也属于本次已确认卸载范围；接管时就提前告知这一点。
4. 保留管理网页及必需的共享组件、SSH 登录服务和其他业务。共享系统依赖或网络设置仅在明确可安全恢复时处理，不盲目卸载整套依赖或清空防火墙。
5. 核验剩余状态并报告实际结果。无法连接、停机失败或文件清理失败时显示待清理，保留目标和失败阶段供重试；不能直接删除所有记录并显示完成。

必要的临时连接能力只用于完成清理。清理成功后撤销本项目独占控制权限；部分失败需要重试时不将密码或私钥长期保存在网页。

## 6. 服务、装配与导入状态机

服务状态、远程装配任务和客户端导入动作分别记录，避免把 SSH 已连接、安装完成、服务可用和设备代理连接混成一个“已连接”。

### 6.1 服务状态

| 状态 | 显示 | 导入与复制 |
|---|---|---|
| 加载中 | 正在检查服务… | 订阅与状态尚未就绪时不发起导入 |

| 状态 | 进入条件 | 允许行为 | 退出条件 |
|---|---|---|---|
| Idle | 初始或前一次任务结束 | 导入、复制 | 用户点击应用 |
| Opening | 有效点击且前置数据就绪 | 尝试唤起；显示“正在打开应用”；等待可见性信号 | 进入后台、等待窗口结束或用户发起新动作 |
| Away | 本次尝试期间页面进入后台 | 彻底取消本次兜底计时 | 用户回到网页；仅恢复界面，不导航 |
| Downloading | 等待结束且页面仍在前台，未观察到唤起 | 尝试打开同一应用的官方渠道一次 | 用户离开、返回或导航被阻止 |
| Returned | 观察到返回，或刷新后恢复待续任务 | 显示继续提示，等待主动点击 | 新的导入动作 |
| Recoverable error | 订阅读取失败、下载导航被阻止等 | 原位重试或复制，不显示已安装/未安装结论 | 错误恢复或新动作 |

### 6.3 计时与生命周期规则

- 每次有效点击生成独立尝试；新尝试取消旧尝试的全部回调。
- 同一尝试最多执行一次下载兜底，防止循环跳商店。
- `visibilitychange` 到隐藏态、`pagehide` 等离开信号取消本次计时。它们仅用于避免误跳，不证明应用打开、导入或连接成功。
- 单纯 `blur` 可能由系统确认弹窗引起，不作为导入成功证据；焦点变化与后台事件必须实机测试。
- 返回、`pageshow`、刷新及浏览器历史恢复均不自动重新启动导入或下载。
- 切换标签、锁屏也可能导致后台信号；返回后保留用户主动点击重试的能力。
- 等待参数 `T_launch` 的初始设计建议为约 3 秒，属于待实机校准参数；不是已确认的浏览器能力或不可调整的产品承诺。
- 用户在系统弹窗中取消打开后，仍可能进入下载兜底；这是 D-07 已接受的残余误判，不新增自建确认页来消除它。


### 6.4 远程装配与卸载任务状态

| 状态标识 | 中文文案 | 下一步与成功证据 |
|---|---|---|
| Unlinked | 尚未添加服务器 | 添加服务器进入默认 SSH 表单，或从备份恢复；购机说明仅作按需帮助 |
| Checking | 正在检查服务器… | 等待只读连接与检查结果；不能改远程系统 |
| ConnectedPendingInstall | 服务器可访问 | 机器身份与检查成功，等待用户开始安装；不代表节点已可用 |
| ExistingCompatible | 发现已有配置 | 保留程序与配置，说明接管范围，等待添加服务器 |
| AdjustmentRequired | 配置需要处理 | 说明不兼容点与影响，查看详情；不自动覆盖 |
| Installing | 正在安装… | 实际下载与配置阶段，显示后台阶段而非模拟进度 |
| Verifying | 正在验证服务… | 安装或接入后验证；尚不显示服务可用 |
| Available | 服务可用 | 已接入且验证通过，可交付订阅；不是设备已连接 |
| InstallError | 安装失败 | 后台确认失败，保留阶段、原因和恢复操作 |
| ProgressUnknown | 暂时无法获取进度 | 仅进度获取失败；查询状态查询，不擅自重装 |
| Uninstalling | 正在移除服务器… | 已确认移除，先摘订阅再停机清理，并显示真实阶段 |
| CleanupPending | 待清理 | 保留机器与失败阶段；重试清理再次处理，不虚报已清理 |
| Removed | 服务器已移除 | 关联订阅已摘除、目标清理核验完成；明确保留项，最后一台则进入空状态 |

云账号另需区分未接入、授权失败、发现中、发现成功且为空、发现成功有机器，不能用空列表吞掉错误。备份另需区分未开启、未执行、成功、失败与过期；这些状态不能用单一绿色“已保护”代替。

## 7. 异常、恢复与边界场景

| 场景 | 设计行为 | 禁止的错误反馈 |
|---|---|---|
| 同时安装小火箭与 Clash | 只尝试用户所点应用 | 失败后依次唤起所有应用 |
| Clash 与 FL Clash 同时安装 | 优先使用能区分目标的入口，允许必要的系统应用选择；无法独占时提供复制恢复 | 承诺按钮名称必然等于系统实际打开的程序 |
| 页面隐藏后返回 | 保留原页面；不再执行旧回调 | 回来立刻再次跳商店 |
| 下载导航被浏览器拦截 | 原位显示官方直接下载链接 | 无限重试、重复开页 |
| 微信等内置浏览器拦截唤起 | 显示在系统浏览器打开的简短说明；保留复制 | 把浏览器拦截直接定性为未安装 |
| 未知设备或桌面 UA 的平板 | 自动识别优先；帮助内可修正 | 给出确定但错误的安装包 |
| 应用已打开但订阅拉取失败 | 留给客户端说明；网页保留重试和复制能力 | 自动认定未安装并更换下载目标 |
| 订阅地址无法读取 | 在原处提示重试 | 跳下载页掩盖服务端错误 |
| 复制失败 | 展开可手动选择的地址 | 按钮显示已复制 |
| 无可用节点或触发服务保护 | 原位置说明不可用，暂停新导入 | 仍显示 Ready、Connected 或保证正常 |
| 同一订阅重复导入 | 固定名称与地址；逐客户端验证新增、更新与确认行为 | 未实测就宣称所有客户端自动去重 |
| 安装后只点商店内“打开” | 原网页仍保留继续提示 | 承诺订阅会自动随安装恢复 |
| 下载网站不可用 | 保留原任务和复制入口，提供官方链接重试 | 断言用户设备不支持 |
| 尚未购买服务器 | README 或添加服务器区域链接统一指南，购买后回到 AI 辅助与 SSH 准备 | 在正常导入首屏堆推荐，或要求先部署网页才能看购买指南 |
| 免费额度不足、已到期或套餐不适配 | 核对完整费用、地区、系统和登录能力；说明可选调整，由用户决定 | 把免费算力当作完整部署免费，自动升级付费或重装机器 |
| 云账号失效或发现失败 | 说明失败并允许重试或手动连接 | 显示没有服务器，或自动安装全部实例 |
| SSH 可达但安装权限不足 | 展示实际检查结果和需要的权限 | 仅因 root 密码可输入就声称可以安装 |
| 原机器已有 sing-box | 兼容则保留配置接入；否则解释调整 | 未确认就换密钥、升级或覆盖配置 |
| 安装中断、刷新或进度未知 | 查询原任务或只读复查机器，保留阶段 | 把读不到进度等同失败并自动另开安装 |
| 卸载清理部分失败 | 关联订阅仍摘除，保留待清理与重试入口 | 直接抹掉目标记录并宣称卸载完成 |
| 管理机兼作最后一个节点 | 允许移除节点，保留网页及必需组件，回空状态 | 连管理网页一起删掉，或禁止移除最后节点 |
| 通用服务器无计费用量 | 如实显示保护未覆盖 | 显示 0 GB 或保证不会超额 |
| 异地备份未配置或失败 | 展示真实备份状态，仍可本地导出 | 将跳过任务标成已成功备份 |
| 恢复文件有效但远程权限缺失 | 记录恢复结果，重新授权并验证 | 上传成功就显示全部服务器正常 |

## 9. 视觉、响应式与无障碍

### 9.1 视觉方向

沿用已选第三个视觉方向的浅纸色与深蓝基础：背景 `#f5f4ed`、正文 `#1f1d18`、次级文字 `#6b665b`、操作色 `#1B365D`。当前原型为普通 Web 页面，使用原生表单、页面滚动及可关闭的网页弹窗；去掉手机外框、设备切换、模拟键盘与状态栏。桌面主内容最大宽度 600px 居中，窄屏保留边距并自然滚动；不把手机截图的像素尺寸当成浏览器固定画布。

- 系统字体优先，清晰区分品牌、状态、操作和帮助。
- 应用按钮同等级、同高度，文字完整可读；图标如使用，只作识别辅助，不替代名称。
- 以间距和对齐分组，避免多层卡片、装饰面板及无任务意义的数据展示。
- 不添加地图、实时速度图或无法验证的连接开关。

### 9.2 响应式与输入

- 有可用服务时，以手机首屏可触达导入操作为目标；无服务器时接入操作在首屏可达。桌面保持紧凑、清晰的操作区，不放大成管理仪表盘。
- 两个按钮优先并排；窄屏或放大文字时允许换行，保持阅读与操作顺序。
- 点击目标建议不小于 44 × 44 CSS px，并保留分隔，避免误触。
- 键盘可完整访问应用、复制、帮助和恢复入口；焦点清晰可见。
- 辅助技术名称可补充“将订阅导入到某应用”，不改变可见按钮只显示应用名的规则。
- 状态变化使用非打断式朗读区域；错误说明与对应控件关联。不能只靠颜色表达状态。
- 按下即时反馈，提交动作在正常点击释放时触发；不增加人为等待动效。
- 支持系统文字放大、减少动效及深浅色偏好；所有状态保持可读对比。
- 从应用返回网页时保持滚动位置和任务语境；不强制将焦点拉到弹窗。

## 10. 工程交接约束与 AI 可读注释

### 10.1 数据与任务

- 服务端提供已授权订阅地址及服务可用性信息；现有 API 路径是否复用由研发确认，不为本规格新增一套账号系统。
- 应用导入所需的订阅格式由适配器指定，避免仅靠通用浏览器 UA 猜测。
- 同一个订阅使用稳定地址与名称。地址失效、鉴权过期与网络故障分别处理，不归入客户端安装检测。
- 任务恢复仅存必要的客户端标识与待续任务，不把真实订阅 token 放进帮助、下载或第三方账号网站地址。
- 登录凭据不写入客户端偏好存储。刷新后按现有鉴权机制重新读取订阅。
- 同会话返回正常恢复；跨浏览器、用户关闭网页或清除站点数据后，不承诺恢复未完成任务。

### 10.2 唤起协议与应用冲突

- Shadowrocket、Clash、FL Clash 分别配置唤起方式与目标格式，不将三类按钮都绑定成同一个通用链接。
- 官方 FlClash 文档列出 `flclash://` 等兼容入口；FL Clash 按钮优先验证其专用入口。
- Clash 各发行版可能与其他应用共用 `clash://`；Android 可评估明确应用目标的方式，适用性必须逐浏览器验证。
- 若操作系统注册关系决定了接收者，网页不得声称能强制覆盖；需记录兼容边界并保证复制恢复可用。

### 12.1 能力对照表

本轮实现验证与第 11 节完整产品验收分开记录；隔离容器通过不将产品场景自动改为已验收，详见[技术方案受控实现](../核心文档/03-技术方案-全自动化装配中枢架构方案.md#controlled-first-install)。

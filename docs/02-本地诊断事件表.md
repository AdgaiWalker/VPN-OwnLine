# 本地诊断事件注册表 (Local Diagnostic Event Registry)

> 单一事实源：由 `server/nodekit/local_diag.py` (`EVENT_REGISTRY`) 代码驱动生成；新增或调整事件后须同步更新本文档，离线门禁强制校验完全一致。

| 事件代码 (`event`) | 所属阶段 (`stage`) | 级别 (`severity`) | 语义说明 |
| :--- | :--- | :--- | :--- |
| `local_ui_started` | `lifecycle` | `info` | 启动本地安装与盲签守护进程 |
| `local_ui_stopped` | `lifecycle` | `info` | 关闭本地守护进程并清空内存凭据 |
| `local_cli_doctor` | `diagnostics` | `info` | 运行本地环境与构建自检 |
| `local_update_checked` | `update` | `info` | 检查远端系统版本更新 |
| `vault_request_created` | `vault` | `info` | 创建盲签凭据输入请求 |
| `vault_submitted` | `vault` | `info` | 用户凭据已存入本机内存并生成不透明句柄 |
| `vault_cancelled` | `vault` | `warn` | 用户取消盲签凭据输入 |
| `vault_consumed` | `vault` | `info` | 一次性消耗内存凭据句柄 |
| `vault_expired` | `vault` | `warn` | 盲签请求或内存句柄到期并清除 |
| `vault_cleared` | `vault` | `info` | 清空指定或全部内存凭据句柄 |
| `vault_tty_fallback` | `vault` | `info` | 无图形桌面环境下启用终端隐身输入回退 |
| `ssh_check_started` | `ssh_check` | `info` | 开始检测目标服务器 SSH 连通性与系统条件 |
| `ssh_check_passed` | `ssh_check` | `info` | 目标服务器身份、环境与 SSH 预检通过 |
| `ssh_check_failed` | `ssh_check` | `error` | 目标服务器 SSH 预检或连接未通过 |
| `ssh_fingerprint_prompted` | `ssh_check` | `warn` | 需要人工核对首次连接的服务器 SSH 指纹 |
| `tencent_lookup_started` | `cloud_discovery` | `info` | 开始通过只读 API 查询腾讯云 CVM 实例 |
| `tencent_lookup_done` | `cloud_discovery` | `info` | 完成腾讯云 CVM 实例列表读取 |
| `tencent_lookup_failed` | `cloud_discovery` | `error` | 读取腾讯云 CVM 实例列表失败 |
| `install_started` | `install` | `info` | 用户已确认目标并触发首次安装任务 |
| `install_stage_changed` | `install` | `info` | 安装任务进入下一阶段 |
| `install_done` | `install` | `info` | 首次安装与交付验收全部通过 |
| `install_attention` | `install` | `error` | 安装或交付验收未完成，等待人工核查 |
| `fallback_ui_opened` | `ui` | `info` | 打开本机图形回退界面 |

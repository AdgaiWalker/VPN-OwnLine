## 1. 产品概述与设计哲学

### 1.1 产品本质与定位边界
* **它不是商业 VPN / 机场服务商**：不售卖共享节点，不赚取流量费用，不收集用户隐私，流量仅在用户自购的服务器与客户端之间点对点流通。
* **它不是本地翻墙客户端**：不替代手机上的 Shadowrocket（小火箭），也不替代电脑/安卓上的 Clash Verge Rev 或 FlClash（注：sing-box 仅作为云端服务器的高性能运行内核，客户端不使用 sing-box）。
* **用户目标与主旅程（v1.8）**：以“让用户用上自己的专线”为核心，购买服务器→进入腾讯云控制台终端或通过 Mac 本地零依赖自举工具 `setup-mac.sh`→安装配置→导入本地客户端。用户在自己的终端或本地受控环境执行安装；AI 可选，公共介绍页不代管 SSH 登录资料。只读检查与「添加节点」安装触发全闭环，交付真实可访问的公网 HTTPS 管理地址与独立网页凭据。
* **首次设置清单**：四项一行，只展开当前任务和一个主操作；已完成依据系统事实显示。前三项随服务器，客户端项仅为当前设备可选自报。可收起并从帮助重开，不阻挡导入或复制；本地原型已演示，产品尚未接入真实状态。
* **它的真正身份**：**「长青 · 个人专属出海专线 (VPN-OwnLine) 自动化装配母机与全流程辅助中枢」**。把原本高门槛的云主机选购、编译部署、伪装证书、端口仲裁、动态容灾与流量监控，彻底封装为自动化流水线。
* **基础设施适配边界（云厂商支持策略）**：默认通过 **SSH 地址与登录信息**接入兼容的 Linux 服务器，用户名默认 root，可用密码或私钥；添加服务器时直接展示该表单，**下方才提供可选腾讯云授权**。现有原生适配为 Lighthouse（CAM 实例发现、支持的防火墙操作、真实用量包监控与 85% 保护）；其他厂商及 CVM 走通用 SSH，不因推荐购买而获得原生云 API 或账单保护。新入口顺序、独立只读 Connect 与权限差距以专项规格为准，原型与产品应用实现分别报告。

* **节点系统目标与当前边界**：首批目标节点覆盖 Windows 与 Linux；管理端首次完整安装仍以受支持的空白 Linux 为范围。当前新安装入口只能只读识别 Windows 和运行中的 sing-box，Windows 自动安装、已有节点接管与订阅写入尚未实现。不得因检测成功或现有单台机器正常运行而声称 Windows 一键接入已完成。

* **CVM 支持边界**：符合系统要求的 CVM 可通过通用 SSH 方式接入；当前未实现 CVM 原生实例发现、安全组和流量用量 API，不能视为与 Lighthouse 同等自动化。

### 1.2 极简体验铁律：奥卡姆剃刀（如无必要，勿增实体）
1. **消灭技术选择题**：用户在使用产品前已经清楚自身需求。系统默认采用最成熟的伪装协议与最优分流，**彻底剔除“日常省心/跨境防封/极速直连/极客全能”等场景标签与说教文本框**，首屏开门见山直达核心操作。
2. **消灭复制粘贴（客户端一键唤醒）**：在移动端点击按钮通过 URL Scheme 直跳客户端 App 并自动装载配置。
3. **降低超额风险**：目标为全服务器共用可自定义阈值、默认 85%，每台独立按有效真实用量保护；采集延迟、执行失败和其他云费用不在零费用保证之内。是否已可配置以代码与验证为准。
4. **订阅即通知中心**：服务器到期前 7 天，直接在手机客户端的节点名称前植入 `【剩3天到期】`，直观防范突发断网。
5. **用户自持备份**：目标为手动导出加密备份、默认不自动异地发送；恢复前预览并确认，恢复后逐项验证。现有节点 JSON 不等于完整灾备。
6. **纯粹自建装配（坚决剔除外链粘贴）**：坚持全控制权原则，不提供第三方节点粘贴，杜绝失控盲区与僵尸死代码。
7. **功能强关联归位（消灭垃圾桶式杂糅面板）**：彻底剔除孤立堆叠的「运营与系统」卡片。任何按钮只在用户真正需要的上下文出现：节点备份与恢复嵌入节点列表底部；流量保护阈值嵌入配额详情内部；撤销旧订阅收纳于连接弹窗手动链接区；健康检查、诊断快照与服务日志统一归入「运行时和诊断日志」卡片；密码修改归入页脚。绝不在主屏中央开设无关操作的“大杂烩”面板。
8. **额度一眼看清与双端直出（电饭煲哲学）**：日常进站首要关注额度健康。首屏通过 Hero 聚合卡片直出总带宽已用/总量/剩余/安全状态；节点列表每一行单行内嵌该节点的已用/总量/百分比/剩余额度与进度条，彻底消灭下方孤立重复的「SERVER TRAFFIC」表格；订阅端原生注入标准 `Subscription-Userinfo` 响应头，Shadowrocket/Clash 等客户端内无需打开网页，下拉即见已用流量、总配额与到期时间。

## 2. 用户界面与交互规格说明（OpenDesign 极简重构版）

以[《客户端 Web 交互设计规格说明书》v1.7](../设计/客户端Web交互设计规格说明书.md)为详细交互基线：覆盖腾讯云终端首次安装、可选云授权、安装交付、客户端导入、维护及备份恢复。首页显示客户端按钮、复制链接、各机用量与最近 2～3 条日志，其他操作按需展开。

AI 辅助可选，敏感操作由用户接手；客户端选点与路由不在 Web 范围，也不接入 Harness。提示词统一维护在项目 README；[购机信息](../../README.md#need-a-server)只维护在其所链接的购买指南。产品验收仍待执行，不能将演示或历史单测当作工程交付。

### 2.1 当前 Web 界面

当前交互以[专项规格](../设计/客户端Web交互设计规格说明书.md)为唯一详细基线，避免在 PRD 维护第二套按钮、状态机和文案。界面使用中文，应用按钮只显示 Shadowrocket、Clash、FL Clash；字段保留“用户名”“密码”。采用普通响应式 Web 页面，无手机外框、设备切换或模拟键盘。

首次任务依次为购买服务器、进入腾讯云终端、安装与配置、导入客户端；已完成部分跳过，每次只处理一项。公共介绍页不接收用户服务器凭据；腾讯云 API 授权在用户自己的管理服务中可选，和 SSH 登录分开。

安装前检查、用户确认后执行，终端交付验证后的管理地址和独立初始账号密码；首次登录后自行改密。服务就绪后首页显示导入、各服务器用量和最近日志。未知状态不显示已安装、已导入或设备已连接。

### 2.2 实现与证据边界

本地独立 Web 原型已实现界面和模拟操作，不会连接 SSH、访问云账号、安装服务器或打开原生客户端。原型测试不能作为产品真实验收；独立首次安装入口已另行接真实 SSH 与恢复任务；完整产品改版、公网及原生导入链路仍以规格 §12 的缺口为准。

旧双栏仪表盘、旧按钮和旧模块说明已移至[历史摘录](../README.md#变更与历史)，仅用于追溯。现行样式、状态与文案变动统一更新专项规格。

技术实现遵循[轻量技术方案](03-技术方案-全自动化装配中枢架构方案.md)：原生单页 Web、Python 标准库服务（admin.py + nodekit）、Caddy 与 systemd 单轨主控；安装交付由 setup-mac.sh / install.sh 脚本完成。

## 3. 非功能性需求与性能指标

1. **响应速度**：
   * 管理面板首屏渲染耗时 $< 200$ms（纯原生 JS/CSS，0 外部第三方重量级框架依赖）。
   * 订阅接口响应耗时 $< 100$ms（支持万次并发稳定拉取）。
2. **容错与抗脆弱性**：
   * 主控机器故障后应支持经过验证的备份恢复；不承诺固定恢复时长。
   * 目标服务器断电或网络波动时，探活引擎在 60 秒内识别并标记异常。
3. **平台兼容性**：
   * 移动端全面兼容 iOS 15+ (Safari) 与 Android Chrome。
   * 桌面端兼容 macOS Safari/Chrome、Windows Edge/Chrome。

* [x] **按钮归位与额度一体化（电饭煲哲学）**：消除「运营与系统」大杂烩堆叠，节点备份恢复归位至节点卡片、流量保护阈值归位至配额设置、撤销旧订阅归位至连接弹窗、健康检查与日志归入统一诊断日志卡片；Web 端首屏 Hero 额度总览与各节点单行额度进度条一体化直出，消灭底部重复表格；订阅接口注入标准 `Subscription-Userinfo` 标头，客户端无需打开网页直显流量与到期倒计时。

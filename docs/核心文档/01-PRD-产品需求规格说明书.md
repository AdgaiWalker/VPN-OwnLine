## 1. 产品概述与设计哲学

### 1.1 产品本质与定位边界
* **它不是商业 VPN / 机场服务商**：不售卖共享节点，不赚取流量费用，不收集用户隐私，流量仅在用户自购的服务器与客户端之间点对点流通。
* **它不是本地翻墙客户端**：不替代手机上的 Shadowrocket（小火箭），也不替代电脑/安卓上的 Clash Verge Rev 或 FlClash（注：sing-box 仅作为云端服务器的高性能运行内核，客户端不使用 sing-box）。
* **它的真正身份**：**「长青 · 个人专属出海专线 (VPN-OwnLine) 自动化装配母机与全流程辅助中枢」**。把原本高门槛的云主机选购、编译部署、伪装证书、端口仲裁、动态容灾与流量监控，彻底封装为自动化流水线。
* **基础设施适配边界（云厂商支持策略）**：当前版本**以腾讯云轻量应用服务器 Lighthouse 为核心交付端到端深度自动化**（CAM 实例探活、API 自动放行安全组、真实用量包监控与 85% 水位物理断流熔断）；同时**通过通用 SSH 接入其他厂商符合要求的 Debian/Ubuntu 云主机**（输入 IP 与 root 密码自动装配，耗时取决于网络及机器状态）；未来演进路线图逐步扩展至阿里云、AWS、甲骨文云等全云生态的自动化接管。

* **CVM 支持边界**：符合系统要求的 CVM 可通过通用 SSH 方式接入；当前未实现 CVM 原生实例发现、安全组和流量用量 API，不能视为与 Lighthouse 同等自动化。

### 1.2 极简体验铁律：奥卡姆剃刀（如无必要，勿增实体）
1. **消灭技术选择题**：用户在使用产品前已经清楚自身需求。系统默认采用最成熟的伪装协议与最优分流，**彻底剔除“日常省心/跨境防封/极速直连/极客全能”等场景标签与说教文本框**，首屏开门见山直达核心操作。
2. **消灭复制粘贴（客户端一键唤醒）**：在移动端点击按钮通过 URL Scheme 直跳客户端 App 并自动装载配置。
3. **消除欠费风险（85% 刚性熔断）**：轻量云超量按 GB 计费极贵，系统执行 **85% 真实用量刚性断流熔断**，宁可断流也绝不产生超额扣费。
4. **订阅即通知中心**：服务器到期前 7 天，直接在手机客户端的节点名称前植入 `【剩3天到期】`，直观防范突发断网。
5. **文件级快速灾备复原**：主控遇到不可抗力损坏，新机网页端拖拽备份 JSON 文件，秒级原地复原全部节点配置。
6. **纯粹自建装配（坚决剔除外链粘贴）**：坚持全控制权原则，不提供第三方节点粘贴，杜绝失控盲区与僵尸死代码。

## 2. 用户界面与交互规格说明（OpenDesign 极简重构版）

> **客户端 Web 完整流程新方案（2026-10-31，v1.2）**：以专项文档[《客户端 Web 交互设计规格说明书》](../设计/客户端Web交互设计规格说明书.md)为本次交互设计依据，面向服务器主人自用，覆盖云账号/SSH 接入、连接检查、远程装配、已有 sing-box 保留配置接入、客户端导入、维护、完整卸载及备份恢复。正常首屏仍默认英文、按设备平铺应用名按钮、下方复制链接；管理功能收纳在次级区域。本章旧双栏和旧安装描述属于既有管理面板，不可用来覆盖新规格中的只读连接、复用与清理边界。客户端选点与路由不在 Web 范围；不接入 Harness；供研发 AI 阅读的注释约束保留，面向新手的辅助提示词统一从项目 README 获取，帮助查找云服务器、准备凭据和授权。专项方案尚待原型、工程实现与实机验收。

### 2.2 核心模块交互细节

#### 模块一：客户端导出与一键直连（高频第一入口）
* **按钮交互**：
  * **📱 导入小火箭**：触发私有 Scheme `shadowrocket://add/sub://<base64_url>?title=长青·个人专线`，移动端 Safari 点击直接弹窗唤醒 Shadowrocket 并自动写入订阅。
  * **⚡ 导入 Clash**：触发 `clash://install-config?url=<sub_url>&name=长青·个人专线`，唤醒 Clash Verge / FlClash。
* **订阅地址行**：
  * 文案极简为 **`订阅地址`**（消除冗余的“点击复制”字眼）。
  * 点击 `<code>` 地址代码块或点击旁边的「复制」按钮，均可瞬间写入剪贴板，按钮即时反馈「已复制」（1.4 秒后恢复）。
  * 提供「一键更新」按钮，平滑拉取最新配置。

#### 模块二：专属节点卡片与自愈交互
* **卡片头部**：
  * 标题：`节点列表`。
  * 操作区：仅保留核心 **`[+ 添加]`** 按钮（低频的备份与恢复归位至管理抽屉，杜绝误触）。
* **节点信息呈现**：
  * 节点名称（如 `硅谷主力出口`）、出口国旗（如 🇺🇸、🇸🇬、🇨🇳）与所在城市。
  * 延迟探活徽标：实时显示延迟毫秒数（如 `24ms`），绿色表示在线通畅，灰色/红色表示异常。
  * 协议标签：`Reality` / `Hysteria2`。
  * 双落地中继指引：国内中继节点清晰展示 `北京 ➜ 硅谷 (备 新加坡)` 链路。
* **订阅即通知中心（到期预警机制）**：
  * 节点距到期 $> 7$ 天：正常显示名称。
  * 节点距到期 $1 \sim 7$ 天：自动前缀 **`【剩X天到期】`**（客户端节点名与面板同步展示）。
  * 节点距到期 $\le 1$ 天：最高危警报 **`【⚠️明天到期!】`**。
  * 节点已超期：自动从下发订阅中物理剔除，防流量黑洞。
* **原地一键自愈**：
  * 节点发生故障（探测失败）时，节点卡片右侧自动显现 **`[自愈]`** 按钮。
  * 用户点击后，后台秒级执行 SSH 原地杀灭残留进程、纠偏配置文件并重启验真，完成后自动刷新状态。
* **节点管理弹出菜单**：
  * 点击节点卡片任意区域，弹出操作抽屉：
    * `停用/启用此节点`：一键临时从订阅中摘除或恢复。
    * `演练倒换`（仅限中继节点）：在主落地与备用落地之间手动触发倒换演练。
    * `生命周期设置`：配置服务器到期时间（用于触发临期通知）。
    * `编辑`：调整显示名称与监听端口。
    * `删除`：从订阅中移除并在服务器端停止服务。

#### 模块三：流量水位与熔断定心丸
* **安全锁徽标**：
  * 呈现为单行温润胶囊徽章：`🛡️ 85% 自动断流熔断 · 绝无超额扣费`。
  * 告别冗长免责声明，给用户提供坚实心理防线。
* **用量进度条**：
  * 精确读取 Tencent Lighthouse API 返回的真实已用 GB 与总配额 GB（如 `140GB / 1000GB`）。
  * 进度条根据百分比动态变色（正常为深蓝，接近 85% 时预警，超标熔断变红）。

#### 模块四：管理与运维抽屉（折叠收纳）
默认呈折叠状态（`<details class="manage">`），点击展开包含四大专业运维板块：
1. **添加节点（纯自动化装配向导）**：
   * 顶部常驻 **`💡 小白买机与提权 1 分钟指南`**（地域选择、Ubuntu 纯净版、控制台重置 root 密码、放行 22/443/8443 端口）。
   * **向导步骤一**：选择云主机。自动呈现 CAM 探测发现的服务器列表（如 `Ubuntu-TfPo 北京`），或点击「其他服务器」手动填入公网 IP。
   * **向导步骤二**：输入目标服务器 root 密码（高级选项收纳用户名与监听端口）。
   * **装前 3 秒排雷**：点击「开始安装」前置 3 秒 TCP 22 端口探活，若端口阻断立即弹窗给出排查指引。
   * **向导步骤三**：30 秒自动化静默装配流水线（建立连接 $\to$ 探测环境 $\to$ 镜像拉包 $\to$ 伪装配置 $\to$ 启动服务 $\to$ 自验入网），步骤进度与原始日志可视。
2. **运维与体检**：
   * `[一键体检]`：并发对集群所有节点执行端口握手与真实代理出网探测。
   * `[作废旧订阅]`：一键轮换 32 位高熵 Token，旧订阅秒级失效防泄漏。
   * `[备份配置]`：一键下载离线底账 `ladder-nodes-backup.json`（含完整节点参数与应急单机原生直连链接）。
   * `[还原配置]`：点击或拖拽上传备份文件，调用 `POST /api/restore` 原地快速复原节点配置。
3. **运行与诊断日志**：
   * 事件日志：按分级标签（`全部` / `仅看异常` / `订阅拉取` / `探活变动`）过滤。
   * 一键操作：`[复制诊断包]`（脱敏后的一键排障包）、`[刷新]`。
   * 底层日志抽屉：按需查看 `sing-box`、`caddy`、`admin` 实时原始日志。
4. **客户端与更多**：
   * 换设备扫码二维码图片；
   * iOS / Android / macOS / Windows / Linux 各平台官方推荐客户端列表与下载途径；
   * 备用 Clash / 小火箭 Base64 直连串。

## 3. 非功能性需求与性能指标

1. **响应速度**：
   * 管理面板首屏渲染耗时 $< 200$ms（纯原生 JS/CSS，0 外部第三方重量级框架依赖）。
   * 订阅接口响应耗时 $< 100$ms（支持万次并发稳定拉取）。
2. **容错与抗脆弱性**：
   * 主控机器故障销毁时，冷备恢复时间 $< 3$ 分钟（借助 JSON 备份文件）。
   * 目标服务器断电或网络波动时，探活引擎在 60 秒内识别并标记异常。
3. **平台兼容性**：
   * 移动端全面兼容 iOS 15+ (Safari) 与 Android Chrome。
   * 桌面端兼容 macOS Safari/Chrome、Windows Edge/Chrome。

# 交互统计账本 (Interaction Ledger)

> 关联事件表：[docs/02-本地诊断事件表.md](02-本地诊断事件表.md)。本表随界面交互变更同步维护，记录用户必做动作与系统自动消化边界。

| 场景模块 | 用户必做动作 | 系统自动消化项 | 事件标识 |
| :--- | :--- | :--- | :--- |
| 顶栏状态与账户 | 点击异常状态胶囊定位故障；点击账户胶囊改密 | 自动轮询汇聚健康态；自动防浏览器误填充并校验密码强度与一致性 | `ui.status_jump_issue` / `ui.account_update` |
| 连接配置 Hero | 点击「连接本机」「复制链接」「扫码连接」；在弹窗选客户端 | 自动识别系统排序推荐客户端；自动生成订阅 Scheme 与动态 QR；剪贴板失败时自动降级展示可手动复制链接 | `ui.client_hub_open` / `ui.client_launch` / `ui.sub_copy` / `ui.qr_open` |
| 流量配额与账单 | 点击配额条展开趋势；修改熔断阈值；输入云账单已用 GB 核对 | 自动计算多节点木桶短板、安全可用余量、7 日均耗与 14 日预算基准线；自动标记陈旧快照与今日重置状态 | `ui.quota_expand` / `ui.quota_threshold_save` / `ui.billing_reconcile` |
| 节点池运维与自愈 | 展开节点抽屉切换 HY2 / WARP / 住宅 IP / 中转；点击测速或行内重新检测；危险操作二次确认 | 自动隐藏低频管理项至抽屉与菜单；自动解析 Webshare 代理串与 curl 命令；高延迟或机房 IP 自动触发情境唤醒建议；测速并行探测本机 RTT 与骨干延迟 | `ui.node_drawer_toggle` / `ui.ping_refresh` / `ui.node_recheck` / `ui.node_mutate` / `ui.isp_mount` / `ui.relay_bind` |
| 添加节点向导 | 输入公网 IP 与密码或私钥；首次连接核对 SSH 指纹；确认开始安装 | 自动识别粘贴的 PEM 私钥；自动预填节点名与角色；非敏感输入按会话暂存并在离开页面时自动清空内存凭据 | `ui.setup_enter` / `ui.ssh_check` / `ui.ssh_fingerprint_trust` / `ui.node_install_start` |
| 备份、日志与更新 | 导出或恢复加密备份（输入口令）；按级别筛选日志或核验配置一致性；确认系统升级；提交反馈 | 浏览器端 PBKDF2 与 AES-256-GCM 加解密；日志敏感凭据自动脱敏；后台静默检查更新与红点提醒；自动采集脱敏环境、节点状态与前端异常缓冲 | `ui.backup_export` / `ui.backup_restore` / `ui.reconcile_check` / `ui.system_upgrade` / `ui.feedback_submit` |

## 六、全局工程准则备忘

1. **单向不可逆开发纪律**：所有代码修改必须在 `仓库/` 内进行并经由 `./scripts/test.sh`（272 项全离网单测）与 `./scripts/verify.sh`（21 项生产真机验收）；
2. **文档与代码双驱**：任何系统机制变动，必须同步更新相应文档并在 `01-变更记录.md` 追记时间线；
3. **奥卡姆剃刀**：如无必要，勿增实体。坚持以通用 SSH 为基石，拒绝过度工程化。

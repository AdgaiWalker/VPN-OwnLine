## 一、逐条核实与处理

### ① 缺指纹就跳过校验（P1）— 属实，已修

**原代码**：`如果找不到这个架构的指纹 → 警告 → 继续安装`。

**风险**：下载源被替换时，恶意包会以 root 运行。

**改法**：缺指纹 → **直接 exit 3，拒绝安装**；下载后一律比对 SHA256，删掉"无指纹旁路"。

---

### ② health=ok 不代表真能用（P1）— 属实，已修（本次最重要的改动）

**原逻辑**：TCP 通 + TLS 握手成功 → ok；出口 IP 靠 SSH 登进去 curl。

**问题**：Reality 的任何握手都会成功。**uuid 错、sid 错、公钥错，照样绿灯。**

**改法**：新增"真实代理测试"——本机起一个 sing-box 客户端，走这条节点出去，真取一次出口 IP：

```
proxy_exit_ip(node) → 起 socks → curl api.ipify.org → 拿到 IP 才算 ok
```

**负例实测**（端口通、握手通，只改参数）：

| 伪造 | 老验证 | 新验证 |
|---|---|---|
| 假 uuid | ✅ 绿灯 | `proxy`（机器活着，但代理连不通）|
| 假 sid | ✅ 绿灯 | `proxy` |
| 假公钥 | ✅ 绿灯 | `proxy` |

**副作用**：验证变慢（每节点约 8 秒），但换来"绿灯是真的"。

---

### ③ nodes.json 并发读改写（P1）— 属实，已修

**原代码**：`save_nodes` 直接 `open(NODES,"w")` 写；HTTP 线程和后台任务可同时改。

**风险**：丢更新，或写到一半留下坏 JSON。

**改法**：加模块级锁 + **写临时文件再 `os.replace` 原子替换**；读-改-写收敛到 `update_nodes()`。

---

### ④ SSH 不校验主机指纹（P1）— 属实，已修（TOFU）

**原代码**：`StrictHostKeyChecking=no` + `UserKnownHostsFile=/dev/null`。

**风险**：中间人可冒充目标机，骗走 root 密码。

**改法**：改用持久 `known_hosts` + `accept-new`：

- 第一次连：记下指纹（和现在一样信任首次）
- 之后连同一台：指纹不符直接拒绝

> 完全消除需要人工核对指纹，那与"5 分钟装完"冲突。TOFU 是这条路上的合理折中。

---

### ⑤ sshpass -p 把密码放进 argv（P2）— 属实，已修

**改法**：`sshpass -p "$(cat file)"` → `sshpass -f file`。密码不再出现在 `ps` 里。

---

### ⑥ 远端脚本拿不到用户名，控制公钥写错位置（P2）— 属实，已修

**证据**：

```
复现：# 远端 $UNAME 为空
AUTH_HOME=[]

# 结果：mkdir -p "/.ssh" → 公钥写到 /.ssh/authorized_keys
```

**为什么之前没暴露**：老节点在早期版本装过，`/root/.ssh/authorized_keys` 里**早就有**这把钥匙，
所以"验证能用"——**是历史状态掩盖了新 bug**。

**改法**：把用户名以 `__UNAME__` 占位符代入远端脚本，并在 `chown` 时用同一个值。

# 产品修正：删掉「角色」这个概念（2026-10-26 晚）

用户原话：**"不要分国内还是国外的，也不要分中转什么的。节点就是节点。就算是北京、广州，也给我显示出来，也是给我提供服务的。"**

## 之前错在哪

我把"一台机器 → 一个节点"拆成了两种角色（出口/中转），还规定中转不进订阅、国内机器要标红。
**这是我给自己造的模型，不是用户的心智。**

## 改成什么样

| 之前 | 现在 |
|---|---|
| 装的时候必须选「出口 / 中转」| **不选**。选机器 → 填密码 → 点装 |
| 国内机器标红、不进订阅 | 国内机器**自动借道海外节点**，正常进订阅 |
| 订阅里只有 2 条 | **4 条**（新加坡 / 硅谷 / 北京 / 广州）|
| 标题写「2/4 能翻墙」（排除中转）| **4/4 能翻墙** |

## 自动判别怎么做的

装之前先让目标机自己跑一次：

```
curl -m 8 https://api.ipify.org
  成功 → 它能直连国外 → 配成出口
  失败 → 它出不去 → 自动配成「借道最快的海外节点」
```

日志里会写清楚：

```
检查能不能直连国外
直连不了国外，会自动借道另一台节点
```

**用户不需要知道这台是"出口"还是"中转"——他只需要知道它能不能用。**

## 顺带修的一个 bug

装完的判定顺序错了：先标 `done` 再自测 → 前端在自测没跑完时就显示"装好了"，拿不到真实结果。
改成 **先自测、最后标 done**。

- 四个节点全部 ok，出口 IP 全部为 198.51.100.12（美国）
- 手机 390px：4 条节点，无横向滚动

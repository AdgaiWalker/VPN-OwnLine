# 三种拓扑，先选再动手

很多人一上来就照着"主控 + 多节点"搭，其实 90% 的人只需要第一种。

---

## T1 · 单机单节点（推荐 90% 的人）

```
手机 ──> 一台海外 VPS（sing-box + Reality，443）
```

- **成本**：一台机器，$5/月
- **搭建时间**：20 分钟（照 [DEPLOY.md](DEPLOY.md) 或直接用客户端 App 的图形界面）
- **维护**：几乎为零
- **不需要**：面板、订阅、探活、数据库

**什么时候够用**：一个人、一台设备或两三台、节点不出问题。

**这个仓库的东西你都不需要**——直接用 sing-box 官方客户端手写一份配置即可。

---

## T2 · 主控 + 多节点（本仓库）

```
浏览器 ──> 主控服务器（面板 + 订阅 + 探活）
                │ SSH
                ├──> 节点 A
                ├──> 节点 B
                └──> 节点 C
```

- **成本**：主控 1 台 + 节点 N 台
- **收益**：一个订阅链接管所有节点；换设备扫码即用；节点挂了面板一眼看出来
- **代价**：多一台机器要维护；主控挂了不影响已连接的设备，但**加不了新节点**

**什么时候需要**：
- 节点 ≥2 台
- 有非技术用户（家人）要共用
- 经常换设备

---

## T3 · 中转 / 落地分离（本仓库自动判断）

```
手机 ──> 国内入口（低延迟）──> 海外落地 ──> 目标网站
```

- **收益**：入口走国内骨干网，延迟低；落地机器不用暴露给用户
- **代价**：多一跳、多一台机器、配置复杂；**入口机器自己也可能被限速**

**什么时候值得**：
- 直连海外节点延迟高（>200ms）或丢包严重
- 有国内机器闲置

**本仓库怎么处理**：安装时先测目标机能不能直连国外。不能直连的国内机器会自动借道
当前最快的海外节点，用户不需要选「中转」，装完也照常进订阅。没有海外节点可借时，
安装会直接失败并说明原因，不会产生“连上没网”的节点。

---

## 怎么选

| 你的情况 | 选 |
|---|---|
| 一个人用，1 台机器 | T1，不要看这个仓库 |
| 2~3 台机器，想统一管理 | T2 |
| 有家人共用，要扫码即用 | T2 |
| 直连很慢，手上有国内机器 | T3（本仓库装的时候自动判断） |
